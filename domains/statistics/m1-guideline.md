# Statistics M1 canonical source candidate guideline

**Implemented candidate profiles · 2026-11-04. No qualified M1 extraction or accepted knowledge.**

Consume only an explicitly pinned retained integrated PDF product. General LLM,
hosted, specialist, source re-conversion and alternate recognition fallbacks are disabled.
The policy emits private uncalibrated candidates for definitions, qualified assertions,
measurements, table assertions and formula context under the released record contracts.
Located source wording is evidence of a candidate reading, not scientific truth.

Inspect every selected native item. Use canonical same-view text coordinates and
native table/formula identities. Unknown labels receive a bounded broad text route;
empty, missing canonical projection, unsupported and over-limit items stay in the
region denominator. Structural table/formula triggers do not depend on classifier
scores. Whole native structures and coherent sentence windows retain exact offsets;
oversized coherent units have an explicit limit, never silent truncation.

The `default` profile preserves the baseline packs; `described` preserves the separately
selected experimental role descriptions. The explicit experimental `readings` profile adds
`source-role-inspection-1`: separate native per-role state classifications and separately
located classification cues within each actual decoder group. These auxiliary proposal
fields do not add domain roles. Retain all raw state, cue, field and group confidence output.
The returned scores are uncalibrated native decoder scores, with shared model/passage/window
dependence; they are neither independent votes nor whole-record correctness probabilities.

Missing decoder output stays unresolved. An explicit unstated proposal cites exactly the real
source pieces supplied for inspection, including independently pinned related context; it does
not claim an unconsumed enclosing section was inspected. Every role retains its own evidence
set. Contradictory state/value proposals remain unresolved; model inapplicability without a
family-specific justification remains unresolved. No implicit polarity, certainty, modality,
unit or zero is supplied. The supplemental normalized value is explicitly inapplicable because
this source-reading subset performs no numeric normalization. Native blanks retain their actual
inspection states. Recognition-alternative evidence remains outside this canonical assembler.

Use `statistics-reading-occurrence-2` independently of decoder grouping: definition term and
complete defining clause; assertion primary subject, predicate and object; measurement primary
referent, property and original value; native table and data cell. `formula-symbol-first-use-1`
uses the complete primary formula and first exact primary use of its explicitly declared symbol.
Repeated uses of one binding count once; separate symbols retain separate occurrences and
conflicting interpretations of the same binding remain alternatives. Unlocatable macros/glyphs,
missing declarations and ambiguous binding remain explicit limitations. A formula-only record
requires independently inspected unstated symbol and meaning; omissions cannot supply it.

The readings graph runs `resolve.m1_readings` over the immutable extraction product. Changing
finite feature parameters recomputes reading scores without repeating GLiNER extraction. The
resolver seals the complete event inputs, actual feature-instance/input digests and provisional
whole-reading compatibility logit under `independent-complete-reading-logistic-1`. No matching
feature instance yields `not_run`. The three-template pure interpreter receives actual retained
alternative groups through an explicit factor-policy interface. Missing factors/identity policy
yield `not_run`, without uniform probabilities. Production coupling remains disabled pending its
paired benefit comparison; all outputs retain candidate standing.

These profiles end at candidate source readiness. They perform no calibration, acceptance,
consolidation, knowledge publication, selected-result mutation or default adoption.
CPU resource settings are controls; ordinary workload fit and aggregate RSS remain
unqualified pending actual measured assembled journeys and independent references.
