## PTD-07 · Exact retrieval with typed inputs

Consumes [O06](../../functional_reviews/postgresql-typed-domain_2026-11-09.md). Replace str(list(vector.values)) plus Text→VECTOR transient assembly
with official typed VECTOR VALUES/binds. Keep dimension/profile/runtime/source validation; the
selected adapter still serializes text and does not enforce the whole domain contract.

Compose one Core statement sharing a MATERIALIZED eligible CTE. Return tagged membership rows and
bounded dense/lexical/alias channel rows via UNION ALL with explicit channel/rank/score/target facts.
Validate full membership (including duplicates/missing rows) before candidate construction. Retain
Python fuse_candidates, RRF policy, witness/alias precedence, public CandidateList meaning and exact
neighbor semantics. Empty inventory and zero-output channels remain meaningful. Keep final stable
ordering outside UNION branches and preserve the exact-scan barrier.

A table/protocol for the internal tagged rows belongs at retrieval's operation boundary, not in
public knowledge identity. Preserve current cancellation/read snapshot. Retire the four separate
statement execution and literal construction paths only after both resident and transient consumers
use the replacement. Deliver exact current cases plus missing/duplicate/empty inventory, equal ranks,
profile mismatch and witness/alias precedence. Compare independent channel membership/ranks, not
only final top-k. Assess unusually large inventories qualitatively; investigate a serious regression
if the tagged full-membership result amplifies work, without assuming a benchmark is obligatory.

## PTD-I03 · Resident transformations and preparation

Inspect actual resident publication/selection transformations before selecting a Core write consumer.
Current protected native INSERT/SELECT may already be the complete mechanism. Keep it where adequate;
do not round-trip it through Python simply to adopt Insert.from_select. Select only a transformation
whose intent/contract becomes simpler through Core from_select/UPSERT/RETURNING; preserve native
admission, conflict/identity semantics and settlement in PTD-10. No extra migration engine follows.

Decide any remaining prepared-shape, lambda_stmt, server prepare, pipeline/result batch and row-stream
opportunities at their existing owners. Establish complete determinants and actual repeated work.
Do not layer four overlapping caches. Pipelines exclude COPY/server cursors and may delay failures;
server preparation is physical-session scoped. Close each branch using the composed lifecycle and
an identified consumer or a reason to keep current behavior.

Consumes [O07](../../functional_reviews/postgresql-typed-domain_2026-11-09.md). Independently decide sparse terminology retrieval, page/region multivector
