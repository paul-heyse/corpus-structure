## DDO-07 — Source and primary operations

Build a declaration-to-current-owner inventory from the actual registries and ad hoc entry points.
Assign every active producer its operation profile, subject/input roles, output bundle, semantic
recipe, effects, native publisher and consumers. Inventory the circa33 registered methods and
six descriptor bypass sites from the review, then follow current callers; those historical counts
are not completion quotas. An unclassified supported path prevents retirement.

| Family | Target replacement and immediate consumers |
|---|---|
| PDF capture, recognition, math enrichment | Original immutable source → native/integrated products plus declared source-view discovery population; preserve page/item coordinates, health, source permissions, private streaming and frozen-build custody |
| Source preparation and sentence/profile methods | Typed source/context bindings; explicit analyzed selectors and coverage, shared immutable preparation; no new capture merely to rebind identity |
| spaCy / HanLP | Separate independently versioned native evidence producers; preserve complete native label/role conventions, canonical sentence dependency, availability and original source mapping |
| Formal evidence / constructions | Retain positioned syntax, packed alternatives, operator/role/binder semantics and mechanical witness premises; consuming formal/native products is explicit |
| Maverick / DiPO / D1 / GLiNER | Declared model questions, exact candidate/source populations and typed outcomes; CUDA defaults and numerical policy preserved; raw/effective/batch identity remains evidence |
| Context evaluation and view composition | One admitted selection and choice/support closure; partial/native/source-only views remain distinguishable; no newest-layer lookup |

For each family deliver declaration, generated invocation, native publication, mapped references and
immediate readers together. Share the native kernel, not copied per-family planners. Split semantic
operations without duplicating model residents or introducing a stage barrier per operation.
Ports support prepared batch/stream calls and bounded cancellation/lifecycle capabilities. Models
may execute through the existing NativeHost provider lanes; scheduling/thread/location evidence
is not automatically result identity. Semantic profile projection is compiler-owned.

Do not move actual analyzed scope into mere demand provenance. Source/context membership, selector
bounds and candidate ordering remain exact input determinants. Freeze model/grammar/prompt assets
and declared numerical recipe before deriving the logical request. No adapter reads ambient
configurations or protected reference labels.

## DDO-08 — Downstream and effectful operations

Migrate all math extraction/normalization/symbol-scope, scoped relations, artifact identity,
definition/component/declaration/clause operations, contextual retrieval, M1 extraction/readings,
finite interpretations and structural comparison/dossier/qualification. Reuse primary facts where
the algorithm's contract consumes them; this redesign does not authorize private language
recognizers or change what an existing provider assertion means.

Run-unit structural inputs become immutable authored selections with exact passage/reading roles,
not giant identity-bearing Config objects. Parameters select semantic policy; input pins and
population membership form the binding. Distinct but equal-spelled occurrences remain distinct.
Native SQL authenticates mechanical witnesses and support closure; it does not reconstruct language
meaning independently. Replace method-name/version literals with generated declared bindings.

External-agent queue work declares packet source, guideline/policy/model, authorized effect and
reference scope. Awaiting an agent is a durable demand fate. The pipeline does not call the external
agent or invent a successful derivation before a valid answer arrives. Authored selections and
human/agent corrections are authored facts, not fabricated computational evidence. Effectful
publication/admission actions have their own idempotency receipts; cached payload possession does
not satisfy an unperformed effect. Database/protocol operations compose the same governing model.

Replace registries, config resolution, source_dependencies, OperationDescriptor bypasses, broad
Reader semantics and getattr plan/close discovery as callers move. Keep only admitted capability
bindings and algorithm implementations. New operations must be a declaration, any genuinely new
algorithm and focused independent controls—not new central method-name lists.

## Boundaries and acceptance

DDO-09 supplies shared reuse/trust/change decisions; DDO-10 supplies public and protected read
projections. Their interface design proceeds alongside these families, not after publication is
finalized. DDO-11 coordinates final direct cutover once all active callers are ready. Old machinery
may remain temporarily while implementing an unused target foundation; it is not a supported
parallel authority after adoption.

Qualify authentic provider boundaries on bounded original source, preserving labels, coordinates,
coverage, question/candidate membership, raw scores and failure standing. Use independent semantic
cases for predicate/scope/choice meanings; roundtrip agreement is retention evidence only. Exercise
same source under a changed operation declaration, equal-content output, empty/partial source,
missing candidate and a wrong native witness. Test a non-statistics context without page-specific
routing. Required actual provider work cannot be replaced with mocks or successful import checks.
No automatic training/model replacement or extra NLP taxonomy is implied by this structural redesign.

## Author-once operation migration — Python I01/I02/I04/I05

Consumes [operation ownership](implementation-contracts-and-fingerprints.md#I01) and
[consumer retirement](implementation-contracts-and-fingerprints.md#I05). DDO-00 selects the authority
per actual operation; DDO-07/08 migrate its definition, algorithm, invocation, inventory and immediate
readers together. Coupled Python operations own typed methods plus non-derivable domain metadata;
external protocols keep independently specified declarations. Remove duplicated owner/symbol/signature,
manual behavior version/source_dependencies and getattr capability lists after compiled replacements
and their consumers work. Broad executable custody and explicit non-Python assets remain.

Griffe [inherited members/aliases](https://mkdocstrings.github.io/griffe/guide/users/navigating/)
and Astroid [class resolution](https://pylint.pycqa.org/projects/astroid/en/stable/api/nodes/astroid.nodes.ClassDef.html)
retain supplying owners when subclasses override effective class facts. Use the real inherited
interpretation family and one simple algorithm as initial shapes; do not convert all operations to
Python authority or infer domain effects from signatures. Existing providers keep explicit source,
config/numerical/support and capability contracts. Static plugin discovery does not grant execution.

LibCST [codemods/import coordination](https://libcst.readthedocs.io/en/latest/codemods.html) are
conditional tools for actual source-preserving migration. Keep adequate AST generation and native SQL
analysis. Require independent same-signature/body-change, inherited-value, metadata-export and nominal
port cases; no parallel registration or handwritten parameter list should remain necessary to add
one supported operation. Language extraction semantics and protected evaluation remain preserved.
