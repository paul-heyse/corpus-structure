## Evidence target and authority

Release supported statistics-first English subsets of all five core record families through the
CPU path with general LLM extraction disabled. Measure a faithful source reading under a frozen
guideline, rather than scientific truth, proof or causal validity. Selected native/PDF sources
are the intake boundary. Engineering examples challenge shared contracts through another domain
profile; they establish neither an engineering release nor a transferable population estimate.
Ordered procedures remain shadow output until the five core families ship and a separate family
promotion meets equivalent evidence requirements.

[D7](../../design/D7-evaluation-goldens-outer-loop.md) and the existing protected
[semantic evaluator](../../../python/corpus-structure/src/corpus_structure/evaluate/semantic.py)
own reference authoring, sampling and grading. The source has immutable source-bound reference
passes, a completed-cut universe including empty producer reports, archived evaluation policy,
protected insertion/grading and core/full/evidence
[semantic alignment](../../../python/corpus-structure/src/corpus_structure/evaluate/semantic_alignment.py).
Its current prediction extraction uses admitted `AgentStoredBatch` observations; the existing
`agent_claims` reporting contract is not a five-family evaluator. Extend these owners and
their declared model/operation bindings, not a separate scorer or a second reference store.

References are independently authored from selected sources under evaluator authority, using
the existing independent automated author/adjudicator boundary. Production extraction receives
neither reference answers nor evaluator credentials. Explicit evaluator-authorized fitting consumes
only its isolated fitting labels through the protected route. A separate calibration partition
fits final record-event calibration; calibration and final-assessment labels do not enter feature
training, prompts or examples. Do not introduce a human-grading requirement or historical regrading.
Production validators enforce structural conformance; independent
reference readings establish fidelity. A validator rejecting both sides does not establish a
correct reading, and producer predictions cannot define the reference population.

## M1-01 — Early populations, guidelines and partitions

**Proposed.** Start after M1-00 establishes the authorized target and relevant source-selection
authority. Work alongside M1-02 family contract design: guideline roles and supported subsets
inform the schema; schema distinctions inform annotator rules. Close this early contract before
packs, few-shot examples, acceptance policies or final-reference authoring make contradictory
choices expensive. This package does not wait for five working extractors.

Freeze three separately identified populations:

1. A statistics selected-source cut, with source ancestry, original PDF identities, selected view,
   intake/projection/recipe digests and recognition/selection lineage. It supports reproducible
   extraction and supported-subset evaluation.
2. Independently sampled eligible source regions, labelled for all in-scope records including
   regions yielding no candidate or accepted output. This supplies the full-record recall denominator.
3. An original-page/region coverage audit beyond emitted output and supported schemas, accounting
   for absent/unreadable intake, unrun routes and knowledge the representation cannot express.
   It is not interchangeable with supported-subset recall.

Predeclare guideline and family supported shapes, required meaning-changing qualifications,
optional unstated roles, field-state conventions, grouping, source precision and evidence obligations.
Include definition/alias scope, local assertion attribution/negation/modality, exact value/unit/role,
table header/note inheritance and formula/declaration scope. Specify source occurrence versus fact
counting, treatment of duplicates and which core/full/evidence comparison applies. Reuse the model
authority rather than independently defining record meaning in evaluation code. A changed guideline
rule follows its existing operator-direction/version route; ordinary new M1 schema design is not
an implicit permission to change an accepted rule.

Isolate development, feature fitting, final-event calibration and final assessment by credible
source-origin groups. Keep overlapping windows, copies, related editions, repeated tables and
known common origins together. Choose explicit group-separated index splits for any fitting tool.
Current document split support cannot silently claim chapter partitions: if one textbook requires
chapter/section grouping, extend the evaluator partition contract and label results within-book.
Many records within a few books do not supply many independent source groups.

Freeze seed, strata, inclusion probabilities, challenge populations and reference provenance.
Challenge cohorts include clean/degraded prose, mathematical passages, examples, definitions,
tables/notes, lists, cross-references and empty outputs. Keep prevalence-weighted random audit
estimates separate from intentionally difficult cohorts. Reserve prompt/guideline/development
examples outside final assessment; native GLiNER conditioned examples and supervised adaptation
must observe the same boundary. Once final errors influence development, refresh final assessment.

Choose sample size and a source-cluster-appropriate interval procedure from the intended precision
claim and actual independent-group availability before final assessment. A zero-error sample or
degenerate all-correct bootstrap cannot certify the lower bound. If group sufficiency cannot
support the claim, retain the gate as unestablished or explicitly revise the population/scope
through the coordinator; do not multiply confidence through repeated passages.

Completion supplies the versioned population/guideline/partition contract and independent authoring
inputs, including empty regions. Reference production can continue under M1-13 while producers
develop. No source-reading or model-quality result follows from freezing these artifacts.

## M1-13 — Five-family protected evaluation and reference evidence

**Proposed.** Depends on M1-01 population/guideline decisions and the M1-02/M1-03 family/evidence
contract slices, not on predictions or final M1-08 output. Develop protected reference bindings,
family alignment and independently known fixtures alongside producers. Later prediction adapters
consume actual M1-11 publications and preserve record membership across lowered assertions.
M1-10 can consume isolated development/fitting references before M1-13's entire final population
is complete. This avoids a circular requirement that extraction succeed before references exist.

Extend released reference payloads, source frames, pass persistence and alignment for named fields,
multi-anchor evidence, record membership, original/normalized/derived states and family-specific
qualifications. Reference frames pin source view/native addresses and exact projection; do not
relabel text offsets as cell/formula evidence. Reference authors receive source packets and the
guideline without production candidates, factors or accepted output. Retain independent author
agreement, adjudication reasons and quality-sample checks under the existing evaluator protocol.
Historical passes/grades remain immutable; a changed M1 reference binds a new version.

Resolve predictions from the admitted completed result, not raw unadmitted task reports or a moving
selected pointer. Retain units with empty producer output or routing failures in denominators.
Frozen references and a new selected-source cut need explicit stale/new-frame handling, not
automatic relocation with weakened coordinate precision. Refuse unknown family/shape/version
rather than silently scoring an unsupported family as empty or dropping unalignable fields.

| Measure | Required denominator and distinction |
| --- | --- |
| Intake availability | Faithfully represented admitted regions over independently audited original regions. |
| Routing coverage | Eligible targets scheduled over independently identified eligible targets. |
| Candidate capture recall | Gold records for which all required alternatives were generated over eligible gold records; score before final suppression where exposed. |
| Candidate retention | Required generated candidates surviving thresholds, overlap, budgets and decoding over their initially generated population; unavailable diagnostics stay unavailable. |
| Accepted full-record precision | Correct accepted complete records over accepted records. Wrong role, unit, condition, negation or required evidence is a full-record error. |
| Accepted full-record recall | Correct accepted complete records over eligible gold records, including no-output regions. |
| Evidence/qualification correctness | All required valid anchors; applicable modality, polarity, attribution, quantification, conditions and scope. Report partial fields separately. |
| Unresolved/abstention | Eligible cases held unresolved by reason over eligible cases, separate from skipped/failed work. |
| Calibration/selectivity | Proper scores, reliability and precision/coverage at frozen thresholds for final record events; raw heads and exact inference do not certify this. |
| Resource effects | Actual CPU/wall time, peak RSS, latency, cache/replay and correct complete records per resource unit on the declared host/profile. |

Report each family and supported source/quality stratum; distinguish repeated occurrences from
consolidated facts. Implement paired source-group resampling by resampling groups and recomputing
aggregate ratios from contributions. SciPy `stats.bootstrap` supplies machinery, but `paired=True`
does not infer clustering or make a degenerate interval valid. Preserve sampling assumptions and
few-group uncertainty in the result. The frozen procedure must be defensible before interpreting
the proposed lower bound; otherwise report estimates with the release gate unestablished.

Independent tests of the scorer must reject controlled wrong unit, flipped negation, moved condition,
missing parent header, incorrectly inherited note, cross-scope symbol, duplicate occurrence and broken
anchor. Test empty predictions, out-of-cut frames and mismatched releases. Expected readings and
counts come from independent source fixtures, not production assembly or its validator. Protect
reference access in actual evaluator/CPU extraction journeys; static credential configuration
alone does not establish end-to-end isolation.

M1-13 completes with working five-family evaluator/prediction adapters and sufficient independent
reference evidence for the chosen gate assessment. It does not select thresholds using final labels
or pronounce a release. M1-14 consumes its final frozen evidence; M1-15 uses development gap cohorts.

reference/evaluator evidence are implemented and integrated. Earlier focused compile/functional
checks remain appropriate at coherent package endpoints; package boundaries are not broad-gate
triggers. The coordinator accounts for final source/context and the required native functional,

final assessment. Any changed target requires explicit approval and recorded justification. None
is established by this plan.

| Gate | Proposed policy and release consequence |
| --- | --- |
| Source custody | Every required field resolves under the right source/release; zero accepted records with known broken mappings. |
| Coverage | Every selected target has a disposition, including unsupported, partial, failed and skipped. |
| Candidate capture | Working target at least 90% for each core family in its supported subset. |
| Accepted precision | Working target at least 97% complete-record precision and a one-sided 95% lower bound at least 95%, using a predeclared procedure appropriate to the frozen finite population; no record-independence assumption is inferred from source clustering. |

| Calibration | Held-out final-event evidence before a calibrated label; otherwise expose score/decision standing and evaluated policy. |
| Operations | Demonstrate CPU fit, replay, interruption/resume, invalidation and policy-controlled atomic publication. |

**Proposed.** Gap capture starts early with M1-03/M1-05 routing, coverage and context contracts.

descriptions, nested-span policy, windows/budgets, roles, context/header/note retrieval and numerical

use and dependency/lifecycle burden. Return adopt, route, revise, defer or reject with evidence;

### Frozen held-out cut qualification

**Operator-selected, 2026-11-03.** Qualification claims concern the frozen held-out source cut.
Freeze eligible source units and all five supported family subsets before final labels. Origin
separation between development, fitting, calibration and assessment remains; a book's repeated
passages do not become independent origins. Performance on unseen origins remains unestablished.
The90% candidate capture,97% accepted precision, one-sided95% lower bound 95% and70% recall gates
are unchanged.

Prefer exhaustive source-only reference assessment of a manageable cut, including no-output and
unsupported regions, so capture and recall have complete source-side denominators. For precision,
a complete accepted-record census supplies exact cut precision. If sampling is needed, freeze the
full accepted-record frame and uniformly sample without replacement using a predeclared seed and
sample size, then invert exact hypergeometric tests for a one-sided lower precision bound. Fixed
finite-population error labels may cluster by source; the stated SRS design, rather than an
assumption of independent record errors, supplies that sampling distribution. A convenience sample
or accepted-record-only reference set cannot supply source recall. Reference-reading error remains
outside the sampling interval, and a zero-denominator family remains undefined.

Keep the existing origin-group resampling as descriptive comparison evidence. No computed interval,
reference census or pure helper alone establishes extraction quality or release. Freeze the actual
sampling/assessment procedure and population identities before the final assessment. Root owns
its integrated disposition in the coordinator. Primary basis: [Statistics Canada probability
sampling](https://www150.statcan.gc.ca/n1/edu/power-pouvoir/ch13/prob/5214899-eng.htm),
[finite-population exact interval inversion](https://ucb-stat-159-s21.github.io/site/Notes/binom.html),
and [census sampling uncertainty](https://www150.statcan.gc.ca/n1/edu/power-pouvoir/ch6/sampling-echantillonage/5214807-eng.htm).

Current execution disposition and the 2026-11-03 bounded closeout are in the coordinator. Native
machinery, CLI and finite-population calculations have scoped passing receipts; actual Sol/corpus
assessment and the enclosing M1 release remain open. The prepared development helper was not run
