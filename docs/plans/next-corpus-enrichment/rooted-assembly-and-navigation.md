and its authorized grade where the unconnected-supported report requires that standing.
The bound member model and status/read query design can start from existing exact comparison
and root references. The expanded native and detached journeys require the respective
producer outputs.

**Bind a side and keep its meaning.** Retain a reference to the comparison product and
exact side/reading, exact retained component or located clause, qualifying relationship
decision, applicable premise references and original citation. Authenticate actual selected
and origin report/contribution IDs and scope/version. A clause binding reaches the existing
provisional component root only through an explicit qualified relationship to that root.
Keep the existing root identity. Derive member roles for variants, exceptions, revisions
and conflicts only when the binding supports that role, direction and applicability.
A revision still needs actual succession evidence. The opposite side remains visible
as comparison context and obtains membership only through its own qualifying binding.
Preserve the conditions, alternatives and repeated values from the original reading.
For explicit semantic `depends_on` expose qualified endpoints and typed dependencies.

Integrate `derive_dossier_members`, `ops.structural_dossier`, the contribution-backed
membership route where it consumes the same evidence, and their detached reconstruction
together. Preserve exact independently admitted support on facets. Retain binding identity

## NCE-10 · Expose mutual similarity neighbors and explain stranded relationships

**Inputs and sequence.** Consume the authenticated exact target grouping and embeddings
already used by contextual retrieval. Consume witnessed edges and selected outcome evidence
from [NCE-06](witnessed-links-and-artifact-identity.md#NCE-06), exact pair route and comparison
diagnostics from [NCE-07](witnessed-links-and-artifact-identity.md#NCE-07), and root/gap
projections from [NCE-09](#NCE-09) for the complete operator view. Exact similarity and
typed consumer diagnosis can land independently on the current inputs. Admission of
the [NCE-08 challenger](witnessed-links-and-artifact-identity.md#NCE-08) is optional.

**Mutual neighborhood.** Select one stable representative per exact authenticated meaning
group from the frozen eligible inventory, with provenance for every member. Keep one
declared embedding profile, representation policy and source-selection identity. The
initial production route is setwise exact pgvector cosine ranking through the existing
materialized eligibility and validation boundary, using vector 0.8.7 and the pinned Python
`cosine_distance` binding. Compute directed top
`min(5, eligible_peer_count)` per representative. Exclude self, use immutable target
identity to resolve equal distances including the cutoff, and keep distinct zero-distance
peers. Publish the intersection of opposite directed top-k memberships with both ranks,
distance, profile, representative and member provenance, and representation digests.
For a zero- or one-target selection, return a completed empty neighborhood. For a missing,
duplicate, stale or invalid vector in the declared eligible set, record the coverage
failure and withhold the claimed exact neighborhood. Retain independently available
witnessed navigation.

Evaluate scikit-learn 1.9.1 `NearestNeighbors(metric="cosine", algorithm="brute")` as the
offline matched challenger and use it where vectors are already resident for assessment.
Calling `kneighbors(X=None)` excludes self. Ensure stable identity ordering of complete
cutoff ties before checking mutual membership. The database path avoids ordinary export
of vectors and allows selected membership checks and bounded returned edge storage.
Exact ranking still performs pairwise distance work. Use one prepared selection and
publish one reusable bounded projection per useful inventory/profile scope, rather than
re-ranking the whole corpus on each page. Keep resource lifetimes bounded to that
operation and cancellation observable. Compare alternate execution only when workload or
locality changes. [pgvector cosine operator](https://github.com/pgvector/pgvector#querying) ·
[Extension versions](../../pins.md) · [scikit-learn guide](../../libraries/scientific_compute/Scikit-learn.md) ·
[NearestNeighbors](https://scikit-learn.org/1.9/modules/generated/sklearn.neighbors.NearestNeighbors.html)

Provide two visible result kinds in the same bounded browse journey. One has witnessed
typed source relations such as narrower reading, alias, specialization, alternative or
differently scoped version. The other has exploratory cosine neighbors with ranks and
distances. Keep exact groups and identity untouched by similarity membership, paths or
clusters. Use no universal radius threshold in the initial policy.

**Consumer diagnosis.** For a selected reference, compare side or other located
opportunity, join original source opportunity and endpoint representation, eligible
targets, route memberships, refusal or comparison evidence, and exact decision/member
status in the existing reader and detached review. Reuse NCE-07 rule statistics and
scorer explanations. Show why each typed dependency or comparison connection stops at
a particular endpoint. Investigate additional reports for unlinked procedure inputs, unattached exceptions, eligible uses with no selected definition, and broken witnessed dependency paths when an operator needs to trace those outcomes. Start with bounded typed SQL joins for a declared path. Present unsupported or unavailable
witnesses as such. One ambiguous edge does not erase independent direct links. The
diagnosis distinguishes failing layers and preserves separate source-capture, nomination,
selection and display populations. The protected route alone can disclose protected
evaluation inputs.

**Acceptance.** Verify deterministic mutual ranks with fewer than six groups,
equal-distance cutoff ties, distinct zero-distance vectors, duplicate representation
membership, an invalid profile and a stale source selection. Match production pgvector
and scikit-learn results on a frozen suitable frame, allowing declared numerical
tolerance for distances while checking the intended rank and tie behavior. Confirm a
high-similarity neighbor cannot enter an exact meaning group or qualify as a member.
Use one formerly omitted caption opportunity and one represented but unsupported
candidate to establish separate source-to-decision outcomes. When assessing the wider chain investigation, include a broken dependency whose unrelated parallel relation cannot repair it. Verify authorized Reader/CLI/MCP
and portable views show the same selection, layer and evidence boundary. Scoped query
changes publish on the same source and result cut. Preserve explicit comparison metadata
when selections differ across releases.
