## Target and foundation assessment

The [architecture map](../design/README.md), DESIGN §2, D3/D7/D9 and core3.3, heuristics1.0,
test-assessment1.2 and applicable CI1.4 govern the target. Reuse PgAdmin, actual purpose engines,
explicit database policy replay, frozen reference inputs, production invariant validators for
consumer setup, independent semantic expectations, pytest lifetimes and the existing receipt stream.
ADR-0032/0048 preserve committed clone isolation and the named serving seed; ADR-0056 permits
ordinary persistent development without turning disposable test databases into a workflow rule.

**Proposed:** tests depend on explicit scenario/preparation inputs rather than private globals in
another test host. Pure assertions consume pure preparation. Mathematical readings are reused
through explicitly requested later stages, with real spawned deadlines retained. Each fixture
control owns its full premise. Optional observation runs only for an active consumer, while native
operations still enforce their real prerequisites. Assertions observe the named rule/result and
cannot be satisfied by an unrelated earlier failure or invariant-preserving perturbation.

FP-01/03/06 favor coherent ordinary support functions, explicit effects and bounded caller changes;
FP-02/04/05 require independent source meanings, exact observations and actual boundary reach.
FP-07/A4 favors removing unconsumed queries and unrelated preparation, while preserving necessary
commits, independent checks, cold compilation and cleanup. Whole-suite and focused selection must
both fit: splitting fixtures must not replace unrelated NLP work with repeated page parsing.
A new record family changes its meaningful scenario inputs and independent answers; a lint-tool
upgrade changes one thin integration owner; a collection-only run activates no compilation;
concurrent native sessions retain separate effects. These scenarios justify boundaries without a
new registry, cache service, instrumentation framework or numerical cost model. Benefits are
structural hypotheses until implemented; no speedup is claimed.
