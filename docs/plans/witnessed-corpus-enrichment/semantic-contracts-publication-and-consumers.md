## Chosen component and operation contracts

Use released versioned discriminated component variants inside the existing source-contribution/
structural product path, not a parallel store. Common fields identify producing operation/version,
question, physical occurrence/source pieces, named endpoint references, basis, scope/version,
dependencies, interpretation outcome and alternatives. SourceValue retains lexical versus typed
content; actual wire fields are authored once in executable declarations and generated boundaries.
An endpoint reference carries its producing source/product identity, not only a transient sequence ID.

Initial variants and operations are target-local definition/explanation attachment, usage binding,
usage-to-component applicability, scoped unit/note/declaration/condition attachment, typed revision
comparison and qualified dossier membership. Definition applicability consumes component references
and explicit compatibility premises; it cannot invent a defining attachment from a passage label.

A component can be syntactically located yet semantically unassessed, or assessed but not admitted.
Retained interpretation, independent assessment and public standing are separate immutable relations;
do not mutate a private result into an accepted one. Empty/failed/limited/unavailable operation rows
survive zero output. Unknown/uninspected/unstated/incompatible remain distinct where interpretation
depends on them. Score availability/native score and fitted reliability are separate contracts.

Basis is a declared per-operation set (matched cue, returned producer group, native geometry,
model reading, admitted rule derivation), with exact provenance. Duplicate proposals for one physical
span can share location but retain different role/witness/producer identities. Question-relative
compatibility defines allowed edge kinds/multiplicity and exclusive alternative groups. It does
not create transitivity or canonical identity. Existing denotation exclusions still apply to the
identity question, not to legitimate comparison of excluded entities.
