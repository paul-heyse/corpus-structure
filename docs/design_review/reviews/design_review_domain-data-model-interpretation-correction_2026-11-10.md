## Responsibilities and alternatives

D1/D5 retain source/assertion/interpretation distinctions; D2 owns released definitions/artifacts;
D3 owns protected projection/publication; D8 owns reads/custody; D9 owns resource acquisition.
Typed RetainedContributionSemantics and contribution_payload_contracts already support private
release-owned extension dispatch. Native completion validates payload shape and source anchors,
but terminology-specific record/vocabulary authentication is new residual work. Separate retained
interpretations avoid changing complete source-record families and GLiNER configuration. Lexical
lookup proposes candidates; external mapping predicates do not become denotes or global identity.

Full payloads belong once in sealed task results. Compact derived indices buy real selection and
grouping before count/pagination and evidence hydration. Source and review results are independently
pinned, including cursors. Multiple decisions require explicit selection, not latest-wins. Empty
results state the reviewed population. Measurement recognition preserves value/role/referent/basis;
DRAFT and unchecked reference metadata stay explicit. Numerical equivalence remains unassessed.
Vocabulary updates compare archived facts once and survey only explicitly bound retained uses.

## Correction, custody and independent consumption

PDF payload/mapping wrappers flatten original errors before reporting; capture must occur there.
One requested-detail pass retains numeric paths, union causes and repeated keyword errors.
ErrorTree is not lossless. Assessment, examined errors, rendered detail and projection-dependency
coverage remain distinct; yielded-error bounds do not preempt expensive validator internals.

Engine messages and SHACL reports can contain supplied values. Safe default presentation must
not forward raw messages merely because actual/instance fields are absent. Raw evidence is explicit
opt-in; sanitized RDF is never labelled original bytes. Direct detail needs no store. Optional
retention uses the existing operation/result ID; failed validation stays failed. Leased managed
reads additionally verify content digests. Expiry/interruption does not authorize rerunning current
inputs. RDFLib path parse/build is useful after bounded grammar/list admission and cycle checks;
retain native fact-ID witness walks and the two unique Core/SPARQL constraints.

Retained validation-mode JSON Schemas support the new independent authoring consumer. Registry
resolution does not itself refuse conflicting identities or establish full reference closure.
Offline structural preflight does not establish source support, mapping correctness or admission.
Avoid extracting a generic SDK. Pinned exclusion comparison uses authenticated observation/local
identity under a common released interpretation, not generated graph URIs or endpoint labels;
source-declaration and resolution-binding changes remain separate. Scoped SQL before hydration
is the simplest complete route, with no new entailment or store.

Settings keeps constructor/environment snapshots. Actual source-invocation metadata fixes later
ambient rereads and case-sensitive explanation; URL masking must include Nemotron. Wrappers preserve
native source ordering/state and retain safe metadata only. Nested BaseModel defaults can legitimately
be constructor contributions; no default-origin defect is inferred from that alone.

## Revealing scenarios and acceptance

- Competing source reviews preserve original records and require explicit result/decision selection.
- Gaussian, sample variance and out-of-universe families challenge meaning independently of lookup.
- Lifetime/PDF/CDF values in one paragraph challenge role-sensitive recognition.
- Label-only/removal/mapping updates retain original archived meanings and bounded known uses.
- Nested unions and repeated failures preserve one original capture and independent coverage facts.
- Credential-like raw values are withheld by safe detail; raw custody stays separately explicit.
- Mutated/expired managed artifacts refuse through leased content verification.
- An invalid offline subtype rejects structurally without claiming source/admission checks.
- Different realization pins do not masquerade as changed source declarations.
- Later environment changes do not rewrite constructed-snapshot explanation.
- High-degree populations bound examined work/intermediates, not only response rows.

## Judgments and bounded decision

A1 localizes interpretation, evidence, comparison, export and settings changes with named consumers.
A2 makes source, mapping, recognition, admission and completeness explicit. A3 composes existing
contribution/schema/result boundaries without another source-record model. A4 has a credible
route through compact selection, delayed hydration, operation preparation and bounded optional custody.
FP-01–07 and relevant supporting rules/gates are satisfied for these Proposed scenarios, not the
enclosing system. CI-G1 preserves attribution/typed relations/unknowns; CI-G2 requires both result
bindings and complete evidence closure; CI-G3 retains independent source/negative/known-answer cases.

No additional blocking finding or rule impact is established. Ordinary owner updates and native
forward adoption remain required. DMC-17 owns assembled review/whole-series qualification. Reopen
if implementation introduces automatic selection, cross-release identity alignment, new entailment,
ambient lookup or a second writable authority. DMC coordinator owns implementation/disposition.
