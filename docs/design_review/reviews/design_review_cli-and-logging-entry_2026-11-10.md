# CLI and logging entry target review

**Design/target, combined agent-workflow/library/principle focus; 2026-11-10.**
**Decision: Accept the Proposed target with the explicit sealed-read amendment.**

## Baseline and scope

An independent reviewer assessed the CLD coordinator and three supporting plans against source
`42d20a2ab`, consuming the [scoped audit refresh](../audit/README.md#cld-entry-refresh) published
at `f25d427ed`. Concurrent command implementation is excluded from implementation claims.
Core3.3, heuristics1.0, code-intelligence1.4, binding and test-assessment1.2 apply.

The workload is one operator, bounded local journals, concurrent local logging/MCP producers
and controlled subprocess descendants. External Claude CLI execution is explicitly unselected;
controlled process, actual local MCP/native and other applicable verification remain required.
This review assesses target architecture, not delivery or enclosing deployment qualification.

## Authority and fidelity

| Product | Authority | Identity and completeness |
| --- | --- | --- |
| Command reference | Constructed native tree | Exact external path and selected subtree |
| Configured explanation | Actual settings snapshot | Profile/explicitness; acquired identity separate |
| Correction | Original report and authenticated evidence | Release/product/typed locations and omissions |
| Observation | Identified producer, observational assurance | Parent/producer sequences and collection coverage |
| Progress/action | Existing owner facts and permitted actions | Qualified run/task/attempt; unknown remains unknown |

Select, append, read, seal, correlate and present have explicit owners and failure semantics.
Presenters do not reinterpret domain constraints; provider reports do not become native settlement.
Adding a stage reuses capture/selection; adding a report view reuses the typed report rather than
another classifier. Provider replacement must preserve qualified references and disclose changed
assurance, not merely match event shape.

## Composition and execution fit

Native Typer grammar/reference generation, DMC report selection and configured settings compose
with existing managed custody. The stdlib bridge uses structlog26.1 wrap_for_formatter,
foreign_pre_chain, allowlisted ExtraAdder and one final row/exception owner. Owned nested safe
normalization is necessary: shallow formatter copies do not establish isolation or disclosure
safety. Process routes with invocation-local context avoid competing per-tool global handlers.
Child spools preserve one writer per journal and existing process-group drain/receipt authority.

The reviewer accepts the coordinator's amendment: each independent settled read hashes its full
sealed journal within the8MiB cap before selecting a bounded page. A held owned read/watch scope
may reuse authenticated input; no inode-only authentication cache. Live prefix reads are explicitly
unsealed. Report authentication bytes separately from examined page extent. This bounded integrity
work purchases content authentication without chunk/index machinery and justifies refining the
original blanket avoidance of whole-file rescans.
