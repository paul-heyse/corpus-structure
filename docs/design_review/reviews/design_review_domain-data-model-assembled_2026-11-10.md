## F01 — Repeated whole-report reconstruction · resolved by source inspection

The initial allocator repeatedly validated/encoded the entire report after individual deletions.
Compact output could remove hidden child nodes while reconstructing identical serialized output.
That avoidable amplification violated A4/FP-07 and DP-10/16/21 at the initial baseline.

The correction performs one trusted normalization through the report model, then selects typed
prefixes of already validated observations/nodes with fixed legal marker/coverage updates.
Actual model serialization preserves headers, generated defaults and Pydantic MISSING omission.
A root-prefix index couples observations to preorder nodes and preserves parent closure.
Compact search considers serialized observations directly. Binary search replaces per-deletion
revalidation. Independent regression expectations count one normalization, bound size probes,
and revalidate serialization parity across raw/safe, compact/detail, flat/nested, omitted/default
and escaped/multibyte cases. Execution outcomes remain coordinator-owned.

The source removes the demonstrated repeated work while preserving exact canonical byte bounds,
assessment/outcome, rendering coverage and correspondence. No numerical performance gain is claimed.
No dependency, authority or policy change is required.
