## 2. Responsibility and fidelity

semantics. Native SourceView/product contracts own source custody. Methods emit attributed

## 3. Contract assessment

Current observations.bind_result binds source reports; publication already has occurrence evidence
and evidence roles, and execution-model declares those relationships. These are usable foundations.
They do not yet establish M1 field states, named evidence sets and common record membership across
several lowered assertions. Extend existing meanings before code relies on them. Required
meaning-changing unresolved fields prevent complete-record acceptance. Operation failures, not-run
and unsupported outcomes are not field states. Context serialization retains precision and explicit
synthetic intervals; introduce a new nonancestor contract without weakening existing frame versions.

## 4. Composition and execution fit

The credible proposed route is shared layout/annotations, relational context/candidate reduction,
bounded compatible batches on one resident CPU model, bounded numerical hydration, private
preparation and existing atomic publication. Parent ownership retains connections/leases/fencing;
workers receive detached inputs. Queue limits cover live bytes/work, not only counts. One owner
coordinates spaCy, Torch/BLAS and DuckDB capacity. This is qualitative fit, not measured capacity;
dense/long inputs and aggregate RSS remain release evidence. Protective refusal alone is insufficient.

## 5. Revealing scenarios

A changed table note invalidates affected interpretation even when numeric evidence is unchanged.
A neighboring definition declaration uses its own coordinates in a new context version, not a
fictional ancestor. A checkpoint replacement changes dependent observation identities without
changing released field meanings. Engineering pressure-table transfer preserves gauge/absolute
units and inherited qualifiers without statistics vocabulary entering generic operations.

## 9. Alternatives

Extend existing released relationships: selected. Opaque passage-cited JSON or unrelated flattened
facts loses field precision/grouping or makes consumers reconstruct meaning. Separate family
storage duplicates authority. Weakening old ancestry checks reinterprets an existing contract.
Worker/checkpoint per family fragments capacity and duplicates residency. Deterministic assembly
plus bounded coupled interpretation preserves a useful baseline and evaluates added complexity.
