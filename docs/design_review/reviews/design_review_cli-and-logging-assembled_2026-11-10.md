values before acquisition while domain owners retain cross-field validity, admission and effects.

One bounded journal avoids per-event publication, chunk indexes and another retention service.
The parent serializes append while preserving producer identity/sequence. Torn live tails remain
pending, complete malformed rows stop with corruption, and live content is not immutable.
Independent sealed reads authenticate the whole bounded8MiB journal; held readers reuse input.
That integrity work purchases content authentication rather than relying on inode identity. It
fits this workload under H14/H18–20/H25; materially larger retention/high-volume pagination would
reopen the access-path choice.

Recipe capture reuses its bounded side channel. One safe StepOutput supplies retained text and
compact excerpts; protected-token cuts, byte omissions and unspecified historical basis remain
explicit. Authenticated output reads do not execute checks. The complete route includes bounded
retention/decoding/selection/native joins without a lifecycle per event or another authoritative
native store. FP-07/A4 has a credible qualitative route beyond oversized-answer refusal. No speed,
capacity or measured improvement is claimed.

## 7. Finding

<a id="CLD-AR01"></a>

### CLD-AR01 — Publish acquired visual-resume association before its effect

**Implemented defect; source-inspected 2026-11-10.** Owner: native visual acquisition/dispatch and
CLI composition. Criteria: FP-03/05/06, DP-08/21, A3 and G7.

[`cli/regenerate.py`](../../../python/corpus-structure/src/corpus_structure/cli/regenerate.py)
calls resume_visual_observation before binding run/project. The dispatcher in
[`semantic/visual_requests.py`](../../../python/corpus-structure/src/corpus_structure/semantic/visual_requests.py)
reads/validates retained ownership/options, then executes single/group recognition, recovery and
settlement before returning. Interruption/failure leaves no observation_bindings.
Result inspection consequently reports no native run association and loses native status/resume
relationships. A prose exception note is not the typed association consumed by inspection. The
successful visual wire test does not establish the earlier interruption boundary.

The acquisition/effect composition is incomplete, while native settlement stays authoritative.
This matters because interrupted-operation investigation is the wrapper's purpose.

**Proposed correction:** split native resolution from dispatch using an ordinary finite acquired
resume value. The resolver validates exact run/project/recovery, returns None for nonvisual work,
and lets CLI publish acquired run/project/release before dispatch. Native runtime/task/claim/purpose
and effect fences remain authoritative. Acquisition grants no extra permission. An optional callback
is smaller but introduces timing/failure policy in semantic dispatch; a duplicate CLI query/classifier
repeats native meaning. No generic observer/workflow registry is justified.

**Closure:** source must record validated acquired identity before effects. A focused interruption
after acquisition must leave the wrapper correlated with exact run/target while preserving original
cancellation, native state and receipt custody. Keep wire-equivalence/nonvisual controls. Never
promote merely requested scope.resume_run to acquired identity.

The [CLD coordinator](../../plans/cli-and-logging_2026-11-10.md) solely owns scheduled disposition.

## 8–9. Library fit and alternatives

**Interface-checked, 2026-11-10.** Typer0.28.0/Rich15.0.0/structlog26.1.0 pins apply.
Typer's tree/get_docs_for_click preserves actual usage/options/epilogs without another catalog;
the version-coupled producer closes parent-linked contexts. Handwritten references or subprocesses
add synchronization/preparation without improving the selected responsibility.
[Typer0.28 source](https://github.com/fastapi/typer/blob/0.28.0/typer/cli.py)

structlog wrap_logger, ProcessorFormatter.wrap_for_formatter, foreign_pre_chain, allowlisted
ExtraAdder and metadata removal compose with scoped context. Formatter copies are shallow, so
nested ownership remains necessary. Native ExceptionDictTransformer supplies structure; the thin
adapter adds traversal/output/disclosure bounds. A direct writer would leave useful stdlib records
outside the selected closure.
[Stdlib26.1](https://www.structlog.org/en/26.1.0/standard-library.html),
[contextvars26.1](https://www.structlog.org/en/26.1.0/contextvars.html),
[traceback source26.1](https://github.com/hynek/structlog/blob/26.1.0/src/structlog/tracebacks.py)

Rich literal Text/static containers/selected Syntax supply presentation without another semantic
framework; sanitization stays upstream. Dynamic terminal/styled exports need actual consumers
before adding recording/display/export custody.
[Text15](https://github.com/Textualize/rich/blob/v15.0.0/rich/text.py),
[Console15](https://github.com/Textualize/rich/blob/v15.0.0/rich/console.py)

Final-only retention loses interruption evidence. Immutable chunks/telemetry become credible for
larger retention, independent hosts or remote consumers; they add no demonstrated current value.
