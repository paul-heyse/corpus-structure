# Test reporting under interruption and distributed execution

**Tested · 2026-11-18.** This isolated Linux probe asks what a final pytest JSON report preserves
compared with incremental reportlog on the checkout's Python 3.14.10, pytest 9.1.1, xdist 3.8.0
and Pluggy 1.7.0. It also compares presentation with piped stderr and stderr attached to a
pseudo-terminal. [Review recommendations](../../../plan_improvement_reviews/test-domain-model-and-execution_2026-11-18.md#I07)

Run from the repository root. This command uses a disposable environment and temporary
synthetic test directories. The evidence contains selected observations, with all exercised
cases and phase identities retained in the summary.

```sh
uv run --isolated --no-project --python "$(readlink -f .venv/bin/python)" \
  --with pytest==9.1.1 --with pytest-xdist==3.8.0 --with pytest-reportlog==1.0.0 \
  --with pytest-json-report==1.5.0 --with pytest-metadata==3.1.1 --with pluggy==1.7.0 \
  --with typer==0.28.0 --with rich==15.0.0 \
  python docs/design_review/evidence/2026-11-18_tdm-test-reporting/probe.py
```

| Scenario | Observation |
|---|---|
| Serial and two workers | Both reporters preserved setup, call and teardown failures and the passing item's captured phases. Final JSON included its captured stdout and item metadata. Its serial collector records contained item entries, while the distributed final report contained zero. Neither final report carried the supplied session metadata sentinel. |
| SIGINT during call | The final report existed with exit 2. Its setup-only interrupted item had aggregate outcome `passed`. Reportlog retained the completed item, the interrupted item's successful setup, and session finish. |
| Controller SIGKILL | No final report was written. Four incremental phase reports survived, with no session-finish record. |
| Worker exit | The surviving controller wrote a report. The crashed item had aggregate outcome `failed` and only a setup stage in the final JSON. Reportlog retained the synthetic failure. |
| Typer and Rich | With stdout piped, both stderr modes returned one JSON document and exit 1. The pseudo-terminal rendered progress on stderr. The noninteractive pipe produced no progress output. |
