**Measured, bounded.** `code/numeric_candidates.py` compares direct SymPy
`xreplace(point).evalf()` with NumPy `lambdify(..., modules='numpy', use_imps=False,
docstring_limit=0)` using CSE disabled/enabled, for three real expressions at12 and1200 points.
Run: `uv run python docs/design_review/evidence/2026-10-30_scientific-computation/code/numeric_candidates.py`.
Raw timings and numerical agreement are preserved in `raw/numeric-candidates.json`.

All12 array/direct comparisons agreed at the configured tolerances. The first12-point
compilation took0.03288s versus0.00120s direct evaluation; subsequent compilation benefited from
process initialization. The1200-point cases show substantial potential for an explicitly
batched numerical profile. These are single-run lower-level measurements, not production
comparison throughput, evidence of general branch/complex-domain equivalence or a speed guarantee.

**Selected implementation:** direct evaluation under the admitted computation profiles.
Current scientific comparisons request at most12 deterministic points, may use complex values,
sets, relations and source-domain restrictions, and need precise unavailable/valid-point behavior.
The probe does not qualify generated evaluation for that complete domain. It therefore does not
justify routing all numeric comparison through a generated function or adding an unused backend.
A future explicitly repeated numerical workload can qualify an admitted subset against these
same obligations. No runtime cost estimator or new dependency is introduced.

**Implemented:** operation-local prepared operands/SymPy values and conditions; base evaluations
shared across equation orientations; one set difference; polynomial-only cancellation before
bounded general simplification. Cancellation is restricted to polynomial expressions so it does
not erase undefined denominator points. Each numerical orientation must independently meet the
admitted valid-point minimum. Consolidation and reference decision profiles remain distinct.

Functional verification is owned by the production-efficiency coordinator; the probe neither
regrades stored evidence nor supplies complete scientific qualification.
