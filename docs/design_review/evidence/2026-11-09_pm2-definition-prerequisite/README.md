# Exact definition target prerequisite

The [PM2-09 target inventory](../../../plans/production-milestone-two/retrieval-composition-and-delivery.md#PM2-09)
needs a source-backed definition, with the complete defining content and its directed term
attachment. The [original target run](../2026-11-09_pm2-adoption/README.md)
retained an explanation for the source-labeled binomial passage. This probe distinguishes a
missing source premise from a missing annotation or witness for a premise that is present.

**Tested · 2026-11-09.** The read-only [probe](compare_annotation.py) authenticated the frozen
source selection from run 407, cut 517, view 387 and loaded annotation origin task 1965,
block `#/texts/10950`. It used spaCy 3.8.18 and `en_core_web_sm` 3.8.0. It reproduced the
retained sentence boundaries when reparsing the original token layout. No source rebuilding,
recognition, model download, native write, or change to the default annotation recipe occurred.

The numbered source label and naming predicate are exact. The naming subject identifies a
distribution *of B*; the intervening local declaration defines what `B` counts and refers to
parameters introduced in the opening sentence. A noun phrase that ends before those premises
does not carry the complete defining content. The source has 19 native text pieces across the
selected block. The retained parser puts `p.` at `[52272,52274)` in a sentence by itself, even
though the source has `parameters n and p.`. That token combines the letter from one native
piece and the period from the next. It also tags the first declaration's `n` at `[52085,52086)`
as `ADV/cc` rather than supplying a dependency binding to the local declaration.

Run `uv run python docs/design_review/evidence/2026-11-09_pm2-definition-prerequisite/compare_annotation.py`
to reproduce the read and local replays as JSON. `--target constant-density` repeats the naming
control: both changed arms split the sentence at the exact `C`/period boundary and isolate the
demonstrative naming statement. That changes which antecedent-selection route can run. The
[recorded comparison](comparison.json) preserves both cases. The split is diagnostic only:
formatted initials and abbreviations can cross native text items too.
The [finalized evidence record](records/pm2.definition-annotation-prerequisite.json) binds the
comparison and the probe.

**Blocked: definition target qualification.** The incumbent `definition-scope-1` witness accepts a
single exact dependency-bound content role; it authenticates a numbered label only for its
adjacent display form. No existing reviewed rule combines this label, the exact naming predicate,
and the complete local declaration chain. A bounded successor needs an aligned parse that retains
the declaration roles, a released rule that selects the complete source span and refuses
ambiguous or reported bindings, and matching native admission and detached replay. PM2-03 owns
the next candidate comparison: verify the prepared sentence and token map in `pm2_stage`, then
compare exact HanLP UD/constituency and its added SRL from `pm2_hanlp_products` with the released
spaCy named rules on the same source. Keep the HanLP labels and source pieces on its private
candidate products. A profile whose inherited sentence layout omits a premise cannot establish
coverage of it; a corrected layout is a separately versioned diagnostic arm. Require a unique
local referent, complete premise spans, exact term/content direction, and refusals for competing,
conditional or reported readings before considering a separate native witness contract.
Do not turn the existing naming result or the source label on its own into a definition.
