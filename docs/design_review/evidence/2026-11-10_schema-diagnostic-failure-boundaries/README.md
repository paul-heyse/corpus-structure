# Retained schema diagnostic failure boundaries

Completion-audit probe of two accepted CLI contracts: optional diagnostic publication preserves
the original operation outcome, and unexpected defects retain a distinct exception product.
The CLI and domain preparation are real; only the publication failure and unexpected preparation
exception are injected. No database, provider or activation is involved. The original audit and
repaired rerun use the same probe.

Run from the repository root:

```sh
uv run python docs/design_review/evidence/2026-11-10_schema-diagnostic-failure-boundaries/probe.py
```

The probe uses temporary result stores and reads the actual retained diagnostic through the CLI.
Its JSON output reports observed route outcomes separately from the expected contract checks.
Nonzero exit means at least one accepted product contract was not delivered. The owning
[CLI/logging coordinator](../../../plans/cli-and-logging_2026-11-10.md) consumes the result;
its findings table owns current disposition. The original product source baseline is `0da4f8e614b1`.

**Original failed product-contract checks, 2026-11-10.** Python3.14.10, Typer0.28.0, Rich15.0.0 and
structlog26.1.0 are recorded in `result.json`. The normal retained check exits0, settles passed
and returns a CompileResult. With optional publication alone raising OSError, it exits1, settles
failed and returns no CompileResult. An injected ExceptionGroup retains its original exception
and failed outcome, but its replay is a report5 `validator_failure` with no observation journal.
These original observations established CLD-CA01/02; they do not establish complete exception-content
acceptance. The coordinator specifies independent group/cause/notes/frame closure expectations.

The [original finalized failure](records/schema.failure-boundaries.json) retains its output and hashes.

**Repaired boundaries: Tested, 2026-11-10.** The unchanged probe exits0 at product/test source
`e1be9dc6e395c7d570f6d187b4ce25f3e2b02dbb`. All three independent contract checks pass in
`result-repaired.json`: optional publication failure preserves the successful CompileResult, and
the unexpected group keeps its identity and failed outcome with a separate observation journal.
Its validation-document reader refuses because that artifact is absent. The
[superseding result](records/schema.failure-boundaries-repaired.json) records this bounded repair;
the coordinator owns full exception-content, lifecycle and integrated acceptance evidence.
Result stores are temporary and never committed; no external model or native database execution
is represented as passed by this probe.
