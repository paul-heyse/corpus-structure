# Development interpretation rubric

Judge only the declared question on the named half-open source scope. The
same criteria apply to textbook, procedural and other prose. A statement
that defines a term can also serve another passage function; judge each
offered label independently. Distinguish a condition from the statement it
restricts. Choose a host or a referent only when the source supports the
proposed attachment. Keep a missing candidate, no matching offered
candidate and insufficient source evidence separate.

For literal reads, compare exact wording and native location independently
of normalization. Preserve formula atoms and native item boundaries. A
repeated spelling in offered context cannot establish the source position.
A valid literal with no numeric or date normalization is a partial result.

This is the exposed development partition. The sample names source
opportunities and includes no predictions. Protected A, B and adjudicated C
remain separate submissions under the existing reference owner. A model
output and a failed or absent run are never reference answers.
