# GitHub visitor follow-on comparisons

**Tested · 2026-11-08.** The [visitor coordinator](../../../plans/github-visitor-experience_2026-11-08.md#ghv-06-dispositions)
owns the decisions. This pilot compares the published citation example at
`5bddd141bc5783a69bab4c0350529a5a837dc8ee` with a card derived from the same
DOM text and links. Playwright 1.64.1 ran on Linux with Chromium 156.0.8078.4.
The script creates both treatments in the same browser page for each size and
asserts identical evidence link destinations.

```sh
uv run --no-sync python docs/design_review/evidence/2026-11-08_github-visitor-follow-ons/compare_card.py \
  https://paul-heyse.github.io/corpus-structure/ docs/design_review/evidence/2026-11-08_github-visitor-follow-ons/raw
```

These captures record that baseline revision. The public site can advance.
Serve the revision's prefix build locally to repeat the comparison on the
original input.

The card's compactness at 390 px did not expose any step or evidence that
was hard to locate in the baseline. Retain the Markdown table. The shared
diagram already identifies its numbered operations and named outputs at both
widths. The comparison surfaced no stage that needs a separate icon.

The [three-shot storyboard](storyboard.md) compares the exact retained citation
with its current static path. It found no distinct source-inspection
interaction to justify recording and maintaining a second presentation.
