# GLiNER assertion request separation

**Tested · 2026-11-08.** The probe used the retained source and pinned
model from the [exact run 401 replay](../2026-11-08_gliner-assertion-anchor/README.md).
It compared public requests without changing the provider, model, or source.

The earlier 120-page WCE run 161 had 1,600 assertion executions with no
recorded decoder exception. Its [archived task 849](../2026-11-06_wce-gs120/assessment/run161-final-model001/task-849.json)
has the same effective profile digest, pack version and assertion
declaration as the failed request. Its [execution inventory](../2026-11-06_wce-gs120/assessment/final-source-capture/model161-provider-inventory.json)
includes two assertion executions with partial candidate output. This
history is consistent with a candidate-dependent failure exposed by the
full-book request.

| Request on the retained passage | Prefix words in candidate coordinates | Result |
|---|---:|---|
| Current natural predicate anchor with inline classifications | 24 | Reproduced the retained negative-offset exception |
| Existing latent mode with inline classifications | 24 | Returned four records without a predicate |
| Natural predicate anchor with literal fields only | 0 | Returned one predicate candidate, `positive`, at source characters `[24, 32)` |

The literal-only request also retained the located `real` predicate on an
affirmative/negative control pair where the current request returned the
same literal. Both requests returned no records on the other two pairs.
The probe checked the returned literal intervals against the original
strings. A matching interval establishes location. The retained
`positive` candidate alone does not establish a complete assertion.

A standalone classification request on each control clause returned
labels without source intervals. It incorrectly labelled two affirmative
clauses as negative, one with score about 0.96. This classification setup
does not qualify an assertion field. The controls are illustrative rather
than a quality estimate.

**Proposed · 2026-11-08.** In the M1 adapter, keep the natural predicate
anchor and send only released literal fields in the extraction request.
Keep the released vocabulary for polarity and modality in typed
assembly. Resolve either field only with applicable scoped evidence and
preserve uncertainty when evidence is unavailable. The
[predicate-frame method](../../../../python/corpus-structure/src/corpus_structure/methods/predicate_frames.py)
already locates negation and modal cues and associates them with their
predicate hosts. Reuse those witnesses when they match the extracted
occurrence and support the released value. Evaluate the resulting
assembly and positive and negative controls before retrying the
full-book candidate run. Check other families that mix natural anchors
with inline choices for the same risk. The
[DMA coordinator](../../../plans/domain-model-alignment_2026-11-08.md#dma-13)
owns the cutover disposition.
