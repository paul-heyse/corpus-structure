The probe compares exact site lists, module counts and completeness with the four
[saved root scans](../2026-11-19_udm14-15-disk-cache/raw/code-closure.json). Its independent
controls create temporary Python source and exercise ordinary imports in fresh interpreter
processes. In one package, the scanner includes a dynamic import in an uncalled function.
In another case, eager initialization changes the result and narrowing reports that it cannot
interpret initialization. LibCST supplies an absolute name for a relative alias under the
repository-aware provider. An indirect import falls outside the scanned patterns in a final
case. Editing the loaded helper changes output from 5 to 6 without changing the scanner's
complete digest. [Captured observations](raw/observations.json)

The indirect case demonstrates a limitation of the supported analysis model in a small
fixture. The production root observations show incomplete identity. This scope contains no
production reuse, live database qualification or proof of a replacement design. The
[closure review](../../../plan_improvement_reviews/unified-domain-model-code-dependency-closure_2026-11-19.md)
uses the findings to propose amendments for UDM-10, UDM-14 and UDM-15.
