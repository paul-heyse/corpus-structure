# Defining-text attachment correctness

Assess each exact directed attachment in the frozen source view. A supported event must
name the term being defined and the content that defines it within the source's stated
scope. Identify the exact anchored endpoint roles and preserve compatible alternatives.
A valid endpoint can remain useful when its relationship fails. Record a contradicted
role, direction, scope, or interpretation as unsupported. Preserve genuine ambiguity
and unassessed opportunities as separate outcomes. Use the retained original text and
coordinates. The evaluation supplies development grades for emitted events only.
