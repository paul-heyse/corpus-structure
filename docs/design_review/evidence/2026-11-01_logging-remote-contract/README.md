## Selected contract and limits

Use public logfire.query_client.LogfireQueryClient or AsyncLogfireQueryClient behind the Typer-owned
adapter. Native defaults allow30s HTTP timeout; set an explicit timeout compatible with application
policy. query_json_rows requires min_timestamp, accepts max_timestamp/limit; the client treats naive
datetimes as UTC, but the application should submit explicit aware timestamps. info() uses
/v1/read-token-info; queries POST /v2/query. Error metadata includes retry_after/retryable; retry
ownership stays explicit. Backend query SQL is generated from authorized typed requests, not
arbitrary MCP-supplied SQL. Stable IDs use equality and a bounded permitted time range.

Source exposes Arrow/CSV methods, but actual Arrow/CSV representation, live authorization, retention,
visibility delay and backend error behavior are **not_run**. Local transport tests establish adapter
mechanics only. Any ingestion-to-query journey requires a separately authorized safe write destination;
none was selected here. LOG-10 remains unimplemented and its live acceptance open.

Evidence: raw/contract.json records installed versions, source signatures, synthetic requests and

raw/command.txt is the passing invocation. Initial failures remain in separate raw files.
