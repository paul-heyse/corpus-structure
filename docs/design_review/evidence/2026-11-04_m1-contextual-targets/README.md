The script performs these bounded stages:

1. Read only set1 with the restricted fitter principal and checked successor-run
   applicability. Preserve passes23/24, original records/IDs/content digests and
   source frames. Native protected validation runs before those labels are returned.
2. Use the completed cut's BoundReader and stored annotations. Generate the full
   current source-only context/dual-pack universe under4096 characters/128 pieces.
   There is no annotation rerun or mutable source normalization.
3. Require exact independent role/cue mapping and source-to-codepoint-to-source
   round trips, preserving all ordered real pieces and only the released synthetic
   whitespace policy. Main values and their state/cue labels stay in the same record.
   Actual source/geometry custody supplies nonextractive sidecars; normalization is
   not converted to another extractive value.
4. Audit every proposed context/variant, including excluded requests. All applicable
   readings must be complete and have distinct natural anchor spans. No partial
   family example, silently omitted binding, invented semantic absence, scalar
   broadening or capacity enlargement enters the training payload.
5. Prepare the complete released schema without gold for every request, then use
   the unchanged fixed-schema processor and native target builder for eligible
   targets. Both4096 source words and4096 schema-conditioned subwords are checked,
   max-gold64 is retained, errors raise, and nothing truncates or sanitizes. This
   metadata check establishes no long-context encoder/resource qualification.
6. Admit initial genuine zero-record examples only from the independently empty
   pass23 unit, with all real intervals covered by its frozen exact scopes. Empty
   requests from the nonempty unit remain excluded. Preparation-only empty payloads
   use `build_targets=False` and are never negative examples.
7. Refuse conditioning conflicts, deduplicate equal inputs/targets with all origin
   aliases, serialize raw dictionaries preserving order, and reload/collate those
   exact bytes while comparing conditioning and native target digests.
