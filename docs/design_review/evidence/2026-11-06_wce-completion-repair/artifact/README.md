# Source-work artifact pilot assessment

The independent frame freezes caption and reference opportunities before candidate generation.
The assessor binds exact native and projected anchors to the emitted cohort, retains capture
misses, then measures actual candidate arms and score diagnostics separately. Use the full-file
artifact page from a completed current native run with its configuration receipt.

```sh
uv run python docs/design_review/evidence/2026-11-06_wce-completion-repair/artifact/run_pilot.py \
  --artifact-page PATH/file-page.json --configuration PATH/configuration.json PATH/assessment
```

`artifact_nomination_refs` selects exact retained relationships from ordinary scoped inspection
receipts and the matching verified raw scoped bundle. Include the scoped predecessor selections
in the final full-closure artifact bundle. Add their contribution IDs to the artifact input dependencies and submit the exact
references in `external_nomination_refs`. The registered producer resolves them and validates
their source-backed reference and caption endpoints. The source-authored label frame is
reserved for assessment.

The output separates candidate inclusion, missing source capture, common-support score
diagnostics, and observed automatic union results. It retains exact blocking counts, the
primary model and half and double prior-odds sensitivity, and Splink label tables with explicit
cutoffs. The source review frame remains exposed shared development.
