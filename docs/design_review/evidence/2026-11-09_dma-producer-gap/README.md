# DMA-13 predecessor producer diagnosis

**Tested · 2026-11-09.** [DMA-13](../../../plans/domain-model-alignment_2026-11-08.md#dma-13)
owns predecessor eligibility. This investigation explains why the two
[retained predecessor grades](../2026-11-09_dma-predecessor/README.md) do not
support it. It used the existing Standard and Nemotron integrated product from
task 1627. There was no new recognition, database write, or selection.

## Failure before record acceptance

[inspect_retained.py](inspect_retained.py) uses the read-only run-bound Reader
and SQLAlchemy Core cut membership to reopen the exact candidate task reports.
It projects native decoder role proposals, their source windows and diagnostics,
and the assembled private records. It neither opens the evaluator connection
nor modifies the independent references. The
[retained origin reports](raw/retained-origin-reports.json) distinguish a
missing decoder group from incomplete roles and from an unrun acceptance step.

The first display emitted no formula decoder group; the second produced two groups with only the formula token `g`, without a symbol or meaning. The producer assembled zero private records. |

These are the exact retained candidate reports that precede evaluations 42 and
43. The [whole-view grade](../2026-11-09_dma-predecessor/raw/full-view-grade.json)
and [bounded grade](../2026-11-09_dma-predecessor/raw/section-grade.json) remain
the authority for their own grading scopes. In both original runs the default
candidate route was used. There was no separate M1 reading resolver scheduled.
For each record the default producer emits `independent_complete_reading`
with `not_run` and “fitted record policy instance unavailable”. The separately
named `defined_by_correctness` event also had zero compatible events in the
[run 407 availability report](raw/defined-by-events-407.json) and the
[run 437 availability report](raw/defined-by-events-437.json). This check does
not stand in for a whole-reading fit.

## Existing contextual challenger

[replay_candidate.py](replay_candidate.py) applies the existing named
`extract.m1_candidates/contextual` configuration to the authenticated source
and retained annotations from each selected run. It loads the configured native
CPU GLiNER checkpoint; it invokes the candidate method in process and keeps
the result detached from native task settlement. It does not run the resolver,
fit a policy, apply a grade, or change the archived release.

On [view 409](raw/contextual-409.json), the contextual route decoded 17
definition, 44 assertion and 20 formula-context groups. It still assembled
zero records. The matching prose emitted `g(t)` term proposals without
defining text, and partial assertion groups without an object or condition.
The first display produced full formula surface proposals and an `etX`
surface fragment without its meaning. Other groups contain a possible meaning
with no symbol, or a symbol with no formula. The proposals do not establish a
same-occurrence binding. The second display includes a flattened derivative
surface that provides no independent authority to restore its notation.

On the [Preface view 381](raw/contextual-381.json), the route decoded 21
definition, nine assertion, and 18 formula-context groups. It assembled
one private assertion, in the targeted paragraph, with `experiments` as
subject, `predictions` as predicate, `mathematical tool` as object, and
`chance` as condition. It leaves polarity and modality unresolved. The
object is from the following sentence, and the subject and condition do
not preserve the [independently adjudicated finite assertion and restrictive
object clause](../2026-11-09_dma-predecessor/pass-c-adjudication.md).
No measurement group decoded anywhere in the Preface, including the
window with the trial bound.

## Disposition

The retained controls show a producer coverage and role completion gap as
well as an unapplied acceptance policy. The contextual configuration
does not remedy the missing readings in either replay. Relaxing assembly would give
unsupported fragments record standing; admitting a private heading proposal
would contradict the independent negative. No producer or resolver default
changed in this investigation.

The next producer comparison should exercise source-anchored definition,
assertion, value, and formula roles with separately identified condition and
scope, then retain where each reading was lost. Match exact ordered formula
evidence before deriving a symbol binding or making a symbolic judgment. The
existing statistics controls are exposed development cases from one book.
They may check regression and retention, but cannot supply the disjoint
held-out origin groups needed to calibrate an acceptance policy. Verify
producer output and policy applicability separately before grading a fresh
native run. Evaluations 42 and 43 do not qualify a predecessor.
