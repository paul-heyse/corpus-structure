# Evidence

Probes, spikes and investigations that informed a decision, kept so they are not recreated and so
a later reader can see what a decision rested on. Evidence, never authority: the architectural
collection and the ADRs decide (binding §4).

**Layout.** One folder per investigation, `YYYY-MM-DD_<topic>/`, with:
- `README.md`: the question, how it was run (commands, versions, machine), the result, and which
  review, ADR or plan item consumes it;
- the probe's sources (small text, tracked normally);
- `raw/` for raw tool output (Git LFS, with PDFs, archives, Arrow and Parquet; `.gitattributes`);
- `records/<id>.json`: one record per **finalized** result (ADR-0010): the question, the items it
  informs, method, commands, agents, inputs and outputs with content hashes, headline results,
  outcome, conclusion and consumers. Write the record when a result is accepted (not for every
  run), then `just evidence finalize <folder> <id>`; a revised result supersedes its record
  (`supersedes` / `superseded_by`). The schema is `tools/evidence/record.schema.json`;
- optionally `catalog.sql`: DuckDB tables and views over the folder's own result files, added to
  the catalog under the folder's schema (a Jinja template; `{{ folder }}` is its path).

`just evidence` regenerates the index below and each folder's records block, rebuilds the
catalog (`build/evidence.duckdb`, never an authority) and checks every record: valid, files
present, outputs unchanged since finalization, references resolved. Explore it read-only with
the DuckDB CLI (`duckdb -agent -readonly build/evidence.duckdb`) or `duckdb.connect(…, read_only=True)`;
`records_for('OPEN-D1-1')` lists the current records that inform an item. Reports can take their
figures from the catalog: `just evidence render <report>.md.j2` (Jinja2, undefined names are
errors, the output names the records it used).

Never commit virtualenvs, `target/` directories, stores or caches (`.gitignore` here); record how
to rebuild them instead. Keep a probe runnable where that is cheap; otherwise keep its source and
its recorded output.

## Index

A folder stays while a current decision, open finding, test or build consumes it; otherwise it is
removed and recovered from Git (ADR-0001, [historical recovery](../../README.md#historical-recovery)).
