# Bounded alignment preparation comparison

**Measured,2026-10-30.** `compare.py` compares the complete alignment reports against `ea2d306`
on synthetic one-claim and100-claim populations with a common entity and distinct predicates.
Model preparation/imports are excluded; side construction and all matching are included.
Three repeats retain complete dataclass-report equality. This exercises small and larger indexed
candidate populations, not a corpus, learned model or complete scientific workload.

```sh
uv run python docs/design_review/evidence/2026-10-30_alignment-preparation/compare.py
```

The100-claim median was0.00972s baseline versus0.01024s prepared. This bounded result does not
establish a latency improvement: operation ownership/topology costs offset saved pair scanning
on this shape. Keep the model-bound prepared representation and dependency-directed reuse for
its explicit validity/ownership and repeated-comparison behavior; do not advertise a matching
speedup. Existing independent tests cover map changes, cycles, missing lookups and selected-pair
tie parity. SciPy dense assignment is retained; sparse full matching would add dummy/zero/tie
adaptation. No conversion or CVXPY layer is justified by the present constraints.
