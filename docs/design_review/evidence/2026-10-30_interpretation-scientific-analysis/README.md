## Selection and unresolved work

Retain the qualified Earley/dynamic language and explicit tree outcome contract. Pure summaries
reuse role scans and mathematical comparisons within one resolver operation. When an alternative
is definitely admissible, proven-invalid branches can be removed before nested resolution. The
all-invalid fallback remains; unknown contextual alternatives are never selected by priority.
Unchanged nodes are retained instead of copied, and prepared inputs share lazy conversion under
one complete semantic context. These are concrete avoided passes, not a measured page speedup.

The packed candidate uses `ambiguity='forest'`, `ForestVisitor(single_visit=True)` and a shaped
`ForestToParseTree` projection with existing rule callbacks. The compact forest is real, but this
population's recognition dominates its downstream projection; immediately producing the same
full trees does not remove that work. A new direct forest semantic projection is not claimed
implemented or qualified. The full extended grammar's strict LALR attempt fails at a shift/reduce
conflict; this does **not** rule out useful deterministic subsets.

F01 remains open for recognition improvement. Revisit a broader conservative LALR subset when
source-population evidence establishes useful reach and its admission rule can establish unique
meaning without running Earley as a second verification parse on every input. Revisit direct
forest semantics when selected workloads show ambiguity expansion/interpretation dominating
recognition. A structural pylatexenc pass is not adopted: no repeated structural input work in
this bounded route was established that it would replace. Source coordinates, token keys and
historical answers retain their existing meaning.
