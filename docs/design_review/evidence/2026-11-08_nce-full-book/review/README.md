# Grinstead–Snell whole-book output review

Three independent LLM reviewers examined every physical page of the authenticated
518-page parent. Their page assignments were disjoint. Each page judgment compared
the retained Standard and combined projections with a source-side extraction and
examined native object classes. Reviewers inspected exact objects and rendered
original pages for selected layout, formula, caption and table discrepancies.

The comparison inputs bind Standard run 297/cut 413 and combined run 312/cut 431.
The page packet maps projected fragments through native regions or an enclosing
native item. It records multiple physical locators separately. Poppler supplies
an independent selectable-text reference. Token overlap and missing-line hints
guide inspection, while renderings and native coordinates resolve selected cases.
The review covers every page at that level. Exhaustive visual, cell-by-cell, and
equation-by-equation scoring have separate evidence requirements.

## Findings across page ranges

- **Keep chart recovery and original caption custody separate.** Combined output
  drops shared captions after splitting figures on pages 108, 296, 354 and 470.
  It retains some other captions as text without a native attachment and
  sometimes emits duplicates. Chart extraction can also introduce an invented
  title or quantitatively wrong curve values, as on pages 301 and 334.
- **Check native math through projection.** Both arms retain native readings
  for the matrices on page 416 while projecting only the array opener. The
  same pattern recurs on pages 448, 462 and 468. Combined improves Standard's
  formula/prose repetition on page 142, while weakening exact notation such
  as floor delimiters on page 11 and the gambler's ruin recurrence on page 439.
- **Check table shape and exact cells separately.** Both arms preserve all
  20 values in Table 1.1 on page 11 and agree on the inspected entries of
  Tables 5.2 and 8.1. Neither gives Table 4.2 on page 151 a native table.
  Combined improves the Appendix C age columns on page 510, yet the apparently
  valid grid on page 398 has omitted and displaced Profit values. Both arms
  fail the rotated Appendix B orientation check on page 509.
- **Interpret the three direct-locator gaps in source context.** On pages 4
  and 119 the combined projection has inline text with page regions on its
  native containers. Physical page 506 has a running header and an empty
  body on the original PDF. The combined product's absent body projection
  there reflects the source page.

The [protected comparison assessment](../../2026-11-08_nce-comparison-publication/README.md#whole-book-development-case)
is a separate evaluation of selected passages on pages 151 and 173. It keeps the
independent source judgment and native publication refusal separate from intake review.

The [definition attachment review](definition-attachments.md) covers every
retained component from the four book-wide GLiNER 2.5 and named-producer runs.
Of the 160 components, the reviewer judged 23 usable definitions or naming
equivalences, 25 supported local explanations or examples, 70 materially
incomplete attachments, and 42 unsupported attachments. Unattached candidate
roles and missed opportunities are separate populations.

Every one of the 530 artifact nominations received an independent disposition
across the [initial review](artifact-nominations.md) and the
[remaining unscoped-code review](artifact-unscoped-remainder.md). The results
include useful navigation, co-reference, ambiguous source qualifiers, misleading
shared titles, and two wrong targets caused by an OCR change to a figure number.
No pair met the same-lineage scoring prerequisite.

The [scoped output review](scoped-outputs.md) covers all 29 published Standard
views at report and operation level, with 1,441 sampled contribution chains
checked against retained native items and selected original pages. It finds
supported table-header relations alongside conditions that attach to the wrong
predicate, false actors derived from contents and index entries, and figure or
table references that also receive an unsupported procedure label.

The same review checks all nine contextual proposals against the printed
citations and exact target spans. Every proposal points to the intended
heading. Four additional printed citations were absent from the upstream cue
population, so the contextual results leave book-wide citation recall open.
