# Grinstead–Snell scoped output review

The whole-view review starts with the analysis-eligible source inventory of 29
views from the repaired Standard product. Physical pages below refer to the
518-page original PDF. One selected view can contain pieces on several pages,
and a physical page can contribute to more than one view. The page ranges show
where the selected projections appear. Each exact semantic example gives its
own page, native object and span where those coordinates are available.

[`review_scoped.py`](../review_scoped.py) checks run and cut custody, then
selects the producer reports through exact cut task membership. It counts
contribution kinds, typed subcategories and operation outcomes, including zero
emissions. The packet retains representatives from relation, composite,
predicate-cue and named-link-subject categories and resolves their bounded
endpoint chains back to the pinned native product. A successful text-span match
establishes where the producer found a phrase. The review separately judges
what the phrase asserts in the original source. Formula syntax outcomes record
syntax checks on recognized strings. Mathematical equivalence requires a source
comparison.

The contextual cue-piece graph evaluates source-located section citations against
the full selected heading atlas. Its scoped predecessor is reconstructed on
exact retained cue pieces. The contextual disposition is tracked separately from
the whole-view scoped reports, with original and rebuilt task custody and a
physical cue comparison.
