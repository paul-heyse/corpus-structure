## Meaning and common integration

`source_occurrence` establishes an authenticated nonempty captured-native extent;
it does not establish a correct term boundary or type. `source_literal_quote`
establishes the ordered original quotations from those exact source coordinates.
Neither event grants unit/row/header/note attachment, blank-field inspection,
whole-record acceptance, scientific truth or independent source-quality standing.
Source product pins, mapping precision and any source binding remain visible in
the explicit support facet. Original PDF glyph fidelity remains unestablished.

The released `LocalContributionPublicationPolicy` constrains events, basis and
policy version. `data.local_assertion` is part of the existing typed publication
batch, native COPY staging, canonical batch receipt and atomic consolidation
transaction. It creates no domain membership or parallel publication workflow.
An immutable witness-row identity binds selected/origin task, cut, operation,
contribution, event and exact proof. A separate physical `claim_id` excludes
producer/window observations; readers count claims and witnesses separately.

The native guard prepares exact sealed-cut membership, materializes each origin
report once, decodes indexed products once per origin, and then recomputes each
staged assertion from its immutable source. Generic append refuses these rows;
the existing whole-record admission cap and private graph ingress refusal remain.
Read services retain contribution inspection standing separately from admitted
local source claims. Summary reads select no quotation/evidence bodies; explicit
support reads apply aggregate transfer admission before hydration.

Local source publication does not require a complete record result or a
`record_projection.json` artifact. The contribution-only projection regression
uses a composed domain with that artifact removed, rejects any attempted record
lowering, and independently expects the exact local quotation.
