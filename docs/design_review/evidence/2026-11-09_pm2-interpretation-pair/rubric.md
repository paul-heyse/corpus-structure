# Matched interpretation development rubric

Judge the declared question and assessed source extent. Score exact located
numeric evidence and its complete normalized magnitude; keep the literal,
normalization, and native answer separate. Match a candidate only when the
exact nominated source roles support it. Withheld, missing, unassessed,
unsupported, and empty results do not constitute an affirmative selection.
Source-first judgments contain no prediction identities or confidence scores.

The primary gain case is complete normalization of the fair-coin probability.
The definition classification and the roulette loss magnitude are preservation
controls wherever the incumbent supports them. The other primary facets record
which exact condition host and referent are selected, with separately named
distractors. Report any unsupported new selection separately. A separator can
be context but cannot manufacture a contiguous native source occurrence. The
condition and magnitude meanings are independently judged: do not infer a
public assertion or treat an unasked signed net change as the loss magnitude.

This is exposed development material from Standard and Nemotron source; the
current question families and several locations were previously exercised in
set 33. New version 1 and version 2 predictions remain unopened at freeze.
Two independent source-only passes and a separate adjudication precede the
comparison. Neither protected pass text nor its expected selection enters
either inference request. These cases do not establish release-wide gains.
