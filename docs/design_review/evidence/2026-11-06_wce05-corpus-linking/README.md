## Interpretation and limits

These source families are exposed development material. A successful journey establishes the
specific production/provider/native/read path, not corpus-wide discovery, held-out efficacy,
calibrated correctness or scientific truth. Independent reference/assessment/publication work
has its separate owner. Projecting an already retained term does not count as another discovered
physical source fact.

Semantic grouping is local to each frozen inventory and relationship constraint. It creates no
canonical concept identity or transitive relation. Complete witness inputs retain unsupported
bases, which cannot qualify selected edges. Private vectors and candidate budgets continue to
address private target representations; equivalent origins can consume separate encoding and
nomination capacity. The result reports private and semantic populations separately and makes
no unique-meanings capacity or speed claim.
