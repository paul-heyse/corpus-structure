# Generic role guidance comparison

This detached native CPU comparison asks whether generic, source-anchored role instructions
change the M1 candidate output on the exact retained subsection already used in the DMA-13
producer-gap investigation. It does not fit a policy, consume protected reference data, or
change the registered M1 configuration.

## Binding and comparison

The script `compare.py` reopens run 437, cut 537, source view 409 using the read-only retained
source route from `../2026-11-09_dma-producer-gap/replay_candidate.py`. Both arms use release
`release:d79e9a624e59a449d549a933bc512c3fed2780c1198276596a486696084b727f`, M1 method version
10, configuration `default`, and registered config key
`cfg:4d2309876b3858372123a94b90354fed`. The retained native product digest is
`35f4384ea386e630448d804621c0767881650937c45cd4294182cb0dd91ce8fb`; projection and recipe
digests are retained in `raw/comparison.json`.

The baseline calls the ordinary method. The comparison arm calls the explicit
`run_generic_role_guidance_comparison` helper, which adds neutral instructions to literal and
classified roles while preserving configured role descriptions. The arms therefore retain the
same registered config and method identity, with distinct pack fingerprints and diagnostic
request IDs. The helper is not wired into default execution.

## Result

Baseline produced 8 definition and 2 formula-context decoder groups, no assertion or measurement
groups, and no assembled private record. Generic role guidance produced 9 assertion, 4 definition,
and 2 measurement groups, no formula-context groups, and one assembled private assertion record
with the full set of declared assertion role names. The decoder's role-distribution change is
observable, but this run does not establish that the newly assembled record matches an intended
reading. `protected_reference_grade` is `not_run`; the protected references were not loaded into
inference or this comparison artifact. This is diagnostic improvement in candidate coverage,
not qualification or predecessor eligibility.
