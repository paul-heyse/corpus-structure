# T2 decisions

| Item | Decision | guideline_gap | Reason |
|---|---|---|---|
| Statement structure: A one `remark` (anchor unit) containing the supposition and the consequence; B `assumption` (s1) + `remark` (s2) | keep A | yes | §10.3 lets a remark "suppose something and state a consequence" (premise/conclusion roles), but also says a unit that mixes kinds yields one statement per kind and `assumption` is a statement whose only content is a supposition. The packet has no source-marked kind, so the guideline does not settle which applies. Chose the single remark because the remark row explicitly covers it and its claims then take `conclusion`. |
| c_X_normal / c_X_norm (premise, `Suppose again`) | keep A | no | s1 restates the supposition inside the unit, so it is recorded from s1, not from c1 (§10.2: record context premises only when stated only in context). Modality `supposed`, role `premise`. |
| `scope` qualifier on c_X_normal: A `statement`, B none | keep A (`statement`) | yes | §10.7 rule 1 gives unreferenced premises `scope: statement`, but §10.4 gives "Suppose again" the section extent for X; whether the premise should then reach `section` is not settled. Followed rule 1 literally. |
| c_id_mean, c_id_sd | keep A (identical to B) | no | `identical_parameter` is the predicate whose description is this sentence; "respectively" pairs in order (§10.5). Role `conclusion`, modality `asserted`, no `claim` nodes (§10.7 rule 2). |
| c_X_mean (B only, mean_value of X = mu) | drop B | yes | The sentence states which parameters are the mean and sd; E(X) = mu is a derived fact the source does not state (§10.5, last bullet); the "value stated both as parameter and as property" rule (§10.5) is about one sentence stating both, and here the naming is the only statement, which the guideline does not clearly cover. B gave no matching sd claim. |
| unsupported u1 "the mean and standard deviation, respectively" (B only) | drop B | no | The sentence is fully stated by the two `identical_parameter` claims, so nothing is unsupported (§10.5). |
| Aliases of the location/scale parameters: A `\mu`, B `mu` | rewrite to B form (`mu`, `sigma`) | yes | §10.7 keys symbol maps without backslash; the guideline does not say how an alias is written. Used the same spelling as symbol keys. |
