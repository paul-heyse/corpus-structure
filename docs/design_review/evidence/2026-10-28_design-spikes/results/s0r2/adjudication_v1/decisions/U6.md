# U6 decisions

| Item | Decision | guideline_gap | Reason |
|---|---|---|---|
| Statement kinds: st1 `definition` (s1 "Recall that"), st2 `corollary`, st3 `remark` (both passes agree) | keep | yes | §10.3 says "Recall that" mixed units yield one statement per kind but does not say which kind a recalled definition takes; `definition` kept as both passes chose. |
| c_refers_ss1, c_refers_ss2 (A only) vs c_defines_SS (B only) | keep A, drop B's `defines` | yes | `refers_to` is described as "recall the gamma function" (reference §2): s1 recalls a definition made elsewhere, so `defines` (§10.3 Definition row) is wrong, but §10.3 does not say how a recalled definition is captured. c_refers_ss2: s2 refers to the standard score again. |
| c_ss_formula / c_SS_def (definition_formula of the concept) | keep A | no | Conditions carry the restriction sigma > 0 stated with it (§10.7 rule 2); A's span `Z = ... is the standard score of X` is a balanced LaTeX span, B's primary `(X - \mu) / \sigma\)` is a fragment (§10.8). |
| c_Z_def conditions: A cmp sigma > 0, B none | keep A | no | A formula claim carries the restrictions on its own symbols stated with it (§10.7 rule 2). |
| c_X_mean (premise, scope `statement`) | keep A with B's primary span "with mean mu" and "if" as supporting | no | Premise, modality `supposed`; no condition references it so `scope: statement` (§10.7 rule 1). Minimal primary span (§10.8). |
| Extent of X and Z: A `statement`, B `section` | keep A (`statement`) | yes | Nothing in the unit binds X, Z for a section (§10.4), but they are used in two statements of the unit; the guideline does not say which extent a symbol shared by statements of one unit takes. |
| param_values `{}` in c_X_normal, c_Z_SN (A) vs absent (B) | keep B (absent) | no | No parameter values stated (§10.5). |
| c_N_transform (A only) vs unsupported u3 (B) | keep A; drop B's u3 | no | "any normally distributed variable can be constructed from a standard normal variable" is what `transformation_of` describes ("variables in this family arise by transforming a variable of the other family"); a remark without premises takes no role (§10.3). |
| unsupported u1 "standard deviation sigma > 0" | keep (both) | no | No standard-deviation predicate; "mean mu" rule of §10.5 applied to the sd means unsupported item (§10.5 first bullet). The restriction is carried as `cmp` conditions. |
| unsupported u2 "A corollary of the last result" | keep (both) | no | `follows_from` needs a statement of the batch; the last result is outside the unit (§10.3, reference §2). |
| c_X_normal / c_X_norm, c_Z_SN / c_Z_sn | keep A; add "then" supporting to c_Z_SN | no | Corollary: premise `supposed`, conclusion `asserted` with a `claim` node (§10.3, §10.7 rule 3). |
