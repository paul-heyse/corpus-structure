# Unit U6  ·  The Normal Distribution › The General Normal Distribution › Related Distributions  ·  kind: paragraph

## Standing context
[c1] Suppose that \(X\) is normally distributed with mean \(\mu\) and variance \(\sigma^2\).

## Text
[s1] Recall that in general, if \(X\) is a random variable with mean \(\mu\) and standard deviation \(\sigma \gt 0\), then \(Z = (X - \mu) / \sigma\) is the standard score of \(X\).
[s2] A corollary of the last result is that if \(X\) has a normal distribution then the standard score \(Z\) has a standard normal distribution.
[s3] Conversely, any normally distributed variable can be constructed from a standard normal variable.
