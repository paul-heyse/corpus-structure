## CH-01 · Matched Standard conversion

The application `PdfConverter` ran on the same exact book original and raster-only
fixture in both environments. All seven bounded cases returned `success`. The recipe,
asset bindings, physical page selection, and observed device/provider assignments matched.
Native documents agreed field for field apart from the native schema version, which moved
from `1.10.0` to `1.11.0`. These page-range controls compare two isolated readings of
each original page.

| Scope | Matched result |
| --- | --- |
| Book p11 | 20 table cells, caption, and floor formula text and original representation |
| Book p142 | Six formulas and matching prose boundaries |
| Book p151 | One native table with 15 cells, two captions, and four formulas in each isolated run |
| Book p416 | Matching enriched and original formula strings |
| Book p509–510 | 257 and 302 native cells, respectively, with identical contents and spans |
| Raster-only scan | One heading and one text item with matching OCR region and candidate data |

Layout, TableFormer, and formula inference used `cuda:0`. RapidOCR detector, classifier,
and recognizer reported ONNX CPU execution, as selected by the matched source recipe.
The [Nemotron mapper replay](nemotron-mapper-control.md) separately records the A/B/C
results and byte-identical archived p416 Reader response.

The dependency lock and both installed command help surfaces passed with Typer 0.28.0.
The original spaCy wheel URL returned HTTP 504 during resolution. The GitHub asset API
provided identical bytes with SHA-256 `1932429db727d4bff3deed6b34cfc05df17794f4a52eeb26cf8928f7c1a0fb85`.
The resolver used that local copy, and the final lock kept the original URL and hash.
`uv lock --check --offline` verified the final lock. Docling Core required `doclang` 0.9.0.

## CH-02 · Local recognition runtime

The pinned local RTX 5090 path ran in BF16 with SDPA and PyTorch reference linear
attention. Remote model code was disabled. On p151, a 1,224 by 1,584 pixel whole page
returned two 4 by 4 tables and all four independently recorded Table 4.2 values. Its raw
response matched the earlier pipeline response after removing bounding box values. The
earlier probe had no submitted-image record for that page.

For p509, the retained upright crop was resized by 2 with Lanczos to 3,422 by 2,276 pixels
to match the prior engine input. Submitted pixels and raw response matched the prior
probe exactly. The mapped Appendix B header differed from independently located glyph
bounds by at most 3.63 points on each edge. The cell alignment caveat remains open.

Both generations returned an unspecified stop reason and parsed successfully. Exact
CPU replay reproduced both native exports without initializing the inference stage or
CUDA. These are direct runtime receipts. The managed recognition request, fenced
publication, and shared Reader have their own acceptance boundary.
