**Tested · 2026-11-09.** The configured local Nemotron endpoint was initially
unavailable. The documented pinned launcher brought it up for the recovery
controls. It performed no recognition. Tests held one PM2 CUDA profile at a
time under the existing device owner.

| Native profile | Results |
| --- | --- |
| [HanLP](raw/hanlp.jsonl) | Missing staged artifacts refused; cold load and mixed sentence lengths passed. Cancellation reaped the child, restored Nemotron and a fresh worker reproduced the initial reply. |
| [Maverick](raw/maverick.jsonl) | Startup refusal, cold load, cancellation, incumbent restoration and exact warm result recovery passed. The first long control was correctly limited at 180 detected mentions versus 128; a smaller admitted request exercised cancellation. |
| [Dipo](raw/dipo.jsonl) | Startup refusal, cold load, cancellation, incumbent restoration and exact warm result recovery passed. The first long control was correctly limited at 180 EDUs versus 128; a smaller admitted request exercised cancellation. |
| [d1](raw/d1.jsonl) | Startup refusal and actual cold load passed. Its [previous native cancellation result](../2026-11-08_pm2-foundation/README.md#locked-native-profiles) retains its earlier scope. |
