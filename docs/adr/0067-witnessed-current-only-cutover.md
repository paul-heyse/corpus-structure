## Context

The operator authorized WCE04–WCE05 execution and explicitly replaced historical-reader and
legacy-control retention with a full design-phase migration. WCE01/03 retention and named
candidates exist; positive component policies and automatic cross-source producers remain open.
The WCE coordinator owns implementation and qualification status.

## Options

1. Keep old report decoders, pair classifier and singleton selector beside the new path.
   Rejected by the operator: duplicate semantics and consumers burden the design-phase target.
2. Reset the complete database. Rejected: authenticated source products are reusable inputs,
   including sources sharing runs with obsolete interpretations.
3. Cut affected producers and consumers over together, faithfully convert sufficient data and
   regenerate insufficient derived populations. Selected: one semantic path with preserved custody.

## Decision

Carry forward ADR-0066's witnessed components, named endpoints, exact operation questions,
qualified bases, explicit alternatives and independent narrow assessment/publication policies.
Retention, assessment and public standing remain separate immutable relations; component support
cannot qualify a larger statement or establish scientific truth. Question-relative compatible
edges do not establish transitivity or canonical identity. Statistics remains the qualification
corpus, with domain-owned vocabularies/policies and no enterprise acquisition prerequisite.
Source-first opportunities and output-first IDs remain frozen independently with original origin
partitions, exposure and protected A/B/C parent custody. Typed comparison and supported-facet
dossier algorithms retain their later WCE scope.

Replace the transition requirements: affected production and control paths accept only the
current contracts. Remove obsolete pair-only interpretation, singleton selection, first-alternative
projections, historical report decoders, compatibility bridges and replaced policy/schema assets.
Historical recorded outputs may inform development comparisons without executable legacy support.
Affected shared comparison/dossier consumers migrate coherently; their later enhancements are not
pulled into WCE04–WCE05. Unchanged whole-statement meanings retain their distinct policy scope;
old definition evidence does not authorize a newly witnessed statement.

Migrate records only when authenticated existing evidence supplies the new meaning. Otherwise
remove obsolete derived dependency closures and regenerate from valid source products. Do not
fabricate witnesses, relabel exposure partitions, delete reusable sources merely because their
run also contains obsolete derived data, or modify another project's database. Preserve plans,
evidence and raw source custody. Installation and migration converge on current contracts only.

Prepare once per useful scope, keep CPU/provider work outside database transaction lifetimes,
and publish exact eligible effects in existing common batches. No new witness store, graph
service, task per primitive or separate reference registry is selected. Semantic output changes
change release identity; execution-budget repairs alone do not.

## Consequences

The supported path is simpler, but old semantic outputs cease to be readable unless faithfully
converted. Dependent inventories, decisions, assessments and assertions require regeneration
when their premises change. Independent positive and refused native journeys, provider checks,
consumer migration and retirement remain implementation obligations in the WCE coordinator.
Acceptance of this operator-directed target does not establish implementation or benefit.
