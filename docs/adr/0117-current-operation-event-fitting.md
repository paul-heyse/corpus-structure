## Context

The current operation-event scorer consumes strict OperationEventParameters, but its fitted producer
still depends on run/cut/reference tables and historical frame addresses. Complete-record policy
fitting asks a different question. Deleting the old fitting route requires a genuine current producer
and preserved independent numerical/scientific controls. Current definition components are nested
inside an actual whole report; they are not native product members. D7 owns fitting/reference
semantics and D8 owns selected transport. The DDO coordinator owns implementation and qualification.

## Options

1. Reuse complete-record fitting or labels derived from score thresholds. Rejected: the event,
features and independent judgment would change meaning.
2. Translate current selections into old task/view IDs. Rejected: invented addresses retain an
obsolete authority and misrepresent provenance.
3. Publish the whole private training frame or use physical execution evidence to conceal its
semantic inputs. Rejected: neither preserves the existing protected fitter boundary.
4. Use selected current frames, the existing numerical fitter and a finite safe parameter authority.
Selected. Current selection/receipt/native authority mechanisms supply the lifecycle; the numerical
algorithm and its independent expectations remain one implementation.

## Decision

**Accepted target; implementation and qualification Proposed.** An explicit output-first event-fit
question freezes ordered selectors of the form exact whole report plus component_id, independently
attributed C labels/facets, source references/origin groups, rubric, partition and exposure. It retains
both actual read/cut/release/runtime selections. No component ID is relabelled as a native member.

A declared frame producer authenticates actual report/component/source custody and exact original
CPU reply-to-report correspondence, then computes the existing finite event features. Preserve
`defining-text-attachment-scope-features-2` and its existing attachment feature arithmetic; the
`defined-by-exact-endpoints-scope-1` event retains exact endpoint counts and explicitly absent native
score. Missing common passages, incomparable anchors and unavailable features remain explicit.
No labels are inferred from a match grade, score threshold or producer output.

A distinct current frame owns canonical bytes/digest and real semantic selectors. The existing
fit_operation_event numerical implementation accepts its actual read-only numerical/event fields;
it does not interpret provenance or construct historical frame aliases. Genuine old callers retain
their original frame identity only until migrated and removed. The fit-purpose producer retains
actual CPU basis/reply/runtime and emits a private fitted result with strict OperationEventParameters
and diagnostics; the exact current frame digest remains part of the parameters' provenance.

An explicit operation_event.authorize command projects only those exact parameters through a finite
native authority leaf. It authenticates the actual fitted result and permitted event/algorithm scope.
Private frames, labels and diagnostics remain undisclosed; physical execution evidence does not
cut this semantic support boundary. The scorer requires the real parameter-producing authority,
not an authored same-shaped value. Generalize the existing restricted frame read to
read_selected_feature_fit_frame with finite record-feature-grade and operation-event-frame variants;
migrate the current record caller and remove the old record-specific API without an alias.

## Consequences

The current event scorer acquires a genuine fitted producer without a second fitter, reader registry
or authority engine. Fitting and ordinary disclosure remain separate operations because their
permissions and information boundaries differ. Existing numerical tolerances and authentic-observation
policy remain; no fresh-fit byte equality or efficacy improvement is promised.

Actual frame/fitter/authorization/scorer, private disclosure, foreign source/cut/label and native
refusal controls remain with the [DDO coordinator](../plans/declared-data-operations_2026-11-12.md).
Old run/evaluation fitting wrappers retire only with their required current counterparts. Acceptance
alone closes no implementation, native or scientific qualification obligation.
