## Context

Actual event fixtures expose two genuine producing episodes for each selected source member:
PDF discovery and retained-view discovery. Address-only acquisition admits both. The event frame
correctly refuses four episode-qualified rows where its exact question selects two sources.
Artifact selection also fails before its policy controls. These are not duplicate SQL join rows.
E5 and a copied-grade tamper fixture may encounter the same ambiguity; their cause remains to be
confirmed. DDO-SI-12/27 in the [DDO coordinator](../plans/declared-data-operations_2026-11-12.md#execution-fit-increment--2026-11-16)
own execution and qualification.

Semantic product/member identity deliberately excludes physical custody and producing episode.
An address therefore cannot also select one proof. Current selected packets and cuts already
carry the required facts, but source-set construction discards them. Contextual witness acquisition
can legitimately reach an upstream producer through a selected frontier use; these uses need not
be identical. [D2](../design/D2-schema-and-guidelines.md#effective-operation-compilation-and-authoring)
owns the interpreted binding and admission contract.

## Options

1. Keep address-only acquisition and require every consumer to tolerate every producer. This
   cannot preserve an explicitly selected episode or scalar role. It expands unrelated support
   traversal and makes publication elsewhere change a consumer's chosen basis.
2. Deduplicate by body, choose the first visible producer, or salt semantic addresses with episodes.
   These lose selected provenance or conflate independent domain identities. None is acceptable.
3. Preserve a separate typed acquisition basis alongside semantic source entries. Selected. Reuse
   exact cuts, computational support references and native selected-read authority. Group proofs by
   shared cut, filter before cardinality and traverse only their selected dependencies. This adds
   a bounded contract across existing binding/admission/CPU owners without a new store or lifecycle.

## Decision

`SourceSetEntry` remains a qualified semantic address. Each frozen source set explicitly declares
either selected-support acquisition or intentionally unqualified all-admissible-support acquisition.
There is no omitted-field compatibility interpretation or implicit producer preference.

Selected acquisition groups entry proofs under exact `CutSelection` values. Each proof records its
selected frontier anchor use, actual producing admission-use/derivation, emitting output role,
position, multiplicity and original output member, separately from the projected selected member.
Native acquisition authenticates cut/project/purpose/current visibility and trust, exact producing
use/output correspondence, member/context and reachability of that actual use through the selected
anchor. Whole-output and explicit-member outputs both retain their real meaning. Existing whole-output
helper semantics survive; a member-aware composition supplies the missing generic authority.

Apply this basis per consuming role before cardinality and narrow support-scope seeds to selected
proofs. Preserve the occurrence through `BoundRoleMember`, input manifests, CPU correspondence and
native attachment. Existing separate attachment statements, locks and live revalidation remain.
No authenticated cut or authority result is cached across invocations.

Only semantic source entries enter source-set request parameters. Incidental read/cut identities
remain acquisition metadata. Existing declared identity requirements determine when selected
episodes or providers affect semantic request identity. Every selected proof remains authenticated
lineage even for value-only consumers.

Use demand-intent-v2 for frozen acquisition encoding, CPU-input-basis-3 for output-occurrence
correspondence and effective model v9 for changed bound-role/native interpreter semantics. The native
ABI descriptor already uses the effective model version; do not invent a second ABI version.
Compiler24 and boundary ABI13 remain appropriate because property interpretation is unchanged.
Reacquire current native/application captures; provide no historical decoder, backfill or fallback.

## Consequences

Consumers can select either genuine proof without changing source identity or weakening exact
population checks. Shared cuts avoid copying whole-book cut bytes per entry. Narrow dependencies
avoid importing unrelated producers; elapsed-time improvement remains unmeasured. Unqualified
acquisition still exposes genuine ambiguity instead of silently choosing a proof.

Migration includes current selected structural/contextual readers, event/artifact/E5 fixtures,
record source/grade choices and protected feature/calibration helpers. Preserve copied-body refusal,
independent fitting populations, source fidelity and revocation controls. Required focused evidence
includes two producers of one address, role-local selection of either, forged/mismatched cut/use/
episode/output/member/context refusal, current-purpose/revocation refusal, direct versus ancestor
support, member versus whole output, and collection multiplicity. Actual consumers and matching
native/application capture remain open. Acceptance of this decision establishes no passing result.
