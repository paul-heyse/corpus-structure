## Context

A new governing model must retain original source, protected reference and evidence custody. Table counts do not select preservation roots or account for external retained bundles. Consolidation also needs exact consumed bindings rather than an independent stale flag.

## Options

1. Reset and regenerate everything. Rejected: original/protected/retained objects have real consumers.
2. Keep parallel legacy/new authorities indefinitely. Rejected: interpretation and currentness diverge.
3. Classify actual preservation closure and perform one coordinated forward adoption. Selected.

## Decision

DDO-00 inventories metadata roots and follows native foreign keys plus typed artifact/evidence/managed/bundle references. Classify preserve under sealed interpretation, explicit reviewed correspondence or disposable regeneration. Unknown required closure remains open. Do not read protected answers to classify custody, automatically rewrite references or infer that migration files preserve instances.

Consolidation/cut materialization is a declared operation over exact values, support, alternatives, population and policy. Currentness names a comparison target; reuse and reverse impact use the same contracts. Newly applicable subjects and absence/population changes remain explicit. Equal admissible results/support stop propagation.

DDO-11 fences old writers, verifies preserved recovery material and exact predecessor, installs target native contracts, imports original custody and regenerates only classified disposable products. Switch callers coherently and retire superseded authority. Uncertain work stays unresolved until authenticated recovery. DDO-12 qualifies the final required union, including retained document and real native/provider/consumer boundaries; historic bounded passes are not current qualification.

## Consequences

This accepts the target, not completed implementation or native adoption. The
[DDO coordinator](../plans/declared-data-operations_2026-11-12.md) owns package readiness and original
finding dispositions. Current selected protocols and archived interpretations keep their existing
ABI/custody guards until the coordinated adoption package replaces their callers. These records
establish the DDO target; full-record retirement of ADR0063/0060/0027/0081/0082/0084/0090/0033/0014/
0085/0091/0050/0064/0067 is not performed while those records still govern live legacy consumers.
DDO-00 records the scoped replacement route; DDO-11 completes reference retirement at cutover.
No data deletion, migration, activation or provider call is authorized by this record alone.
