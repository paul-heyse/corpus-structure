## Context

M1 F23's immutable reconstruction retains all270original C readings. Full-visible scalar/natural
targets cover217decoder readings, with primary assembly custody for204. Existing wider source
neighborhoods can route two missing definitions and four assertions. Two other definitions need
five/thirteen noncontiguous original fragments: scalar bounds include genuine intervening text.
Two assertions share predicate anchors while their remaining fields distinguish records.

The [native inquiry](../design_review/evidence/2026-11-04_m1-native-record-challengers/README.md)
passes eleven metadata controls and two expected scalar refusals without loading a model. List
targets preserve the fragments; latent metadata preserves all15assertions in a wider context.
Formatting orders spans by confidence, requiring an explicit source-order bridge. Latent formation
uses candidates from all fields; the32learned queries belong to the separate anchorless mode.
Metadata success establishes no learned capture. Production currently permits natural/scalar packs.

## Options

1. Keep scalar/natural packs and unsupported cases. This keeps the narrow adapter, but broader
   contexts cannot repair these representation/grouping limits. Missing readings remain counted.
2. Reuse native list fields and latent records behind an explicit new pack/profile contract.
   Selected for bounded qualification: extend the existing compiler, source mapping, inspection,
   assembly and reporting instead of adding model heads or another extraction service.
3. Resize slots, invent surrogate semantic anchors, or add custom grouping/loss machinery.
   Rejected here. Latent already uses distinguishing source candidates; anchorless remains a
   separately triggered challenger. Neither capacity nor injected-gold success proves efficacy.

## Decision

Add an opt-in source policy6/native pack-v2 frontend. Retain default/whitespace and policy4/5
behavior and identities. Route existing whole-block neighborhoods to prose families as well as
formulas, with truthful coverage and complete pinned dependencies. Avoid repeated equivalent
prose requests while preserving their source-region coverage links.

For definition.defining_text, select native list/zero_or_more fragments. The versioned adapter
maps nonempty exact, nonoverlapping source-monotone spans to one already released logical
TextSequence, preserving every original piece and evidence anchor. Sort by verified source/model
offsets rather than confidence. Refuse malformed, overlapping, foreign or unsupported ordering;
never flatten through intervening text, normalize it, infer absence or treat fragments as
independent logical values. Preserve independent states, cues and retained value proposals.

Select latent grouping first for assertions while retaining field semantics, coordinates,
logical occurrence recipes and complete raw/score provenance. Do not resize heads, increase
candidate/gold capacity, introduce hosted fallback or inject inference gold. Per-fragment scores
remain attributed uncalibrated observations with shared dependencies, not independently
multiplied whole-field probabilities.

Fresh reconstruction supervises all applicable complete decoder targets visible in the input,
with full native specifications in conditioning identity. Outer primary custody stays separate.
Preserve all270readings, every exclusion, strict capacities and held-out isolation. Qualify actual
native execution and one bounded faithful-data epoch before an efficacy claim; fresh predictions
and affected feature/calibration evidence still decide acceptance.

## Consequences

Logical source meaning and original references do not change. Producer/pack/profile changes are
explicit run determinants; previous fitted authority is not inherited. Native capabilities retain
their grouping/overlap/candidate limitations, and additional requests consume real bounded CPU.
This reuses existing library work with a small explicit adaptation boundary (FP-01/02/07, H1/H4).
