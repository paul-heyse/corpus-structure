## Context

The operator accepted progressive-review RC01–RC08 on 2026-11-04 and authorized PCE-00–03
execution on 2026-11-05. Current reports retain useful local structure even when record assembly
fails. Whole-reading correctness cannot stand for location, role, attachment or relationship
correctness. The progressive plan owns implementation and qualification; this decision supplies
accepted target authority, not tested implementation.

## Options

1. Keep complete-record acceptance as the only useful product gate. This hides correct local
   structure and makes each consumer reinterpret raw reports. Rejected.
2. Add a second observation store, evaluator or workflow engine. This duplicates source custody,
   release identity, transactions and operator machinery. Rejected.
3. Extend released source products, operation contracts, common native completion and protected
   reference lifecycle. Selected: independently addressable contributions share physical calls,
   report bytes and source context while preserving separate meanings and assessment questions.

## Decision

Make an independently attributable structural contribution a useful enrichment unit. Occurrence,
producer observation, proposed role/type, relationship, qualification and composite membership
have distinct identities. Source location is independent of proposed meaning. Preserve exact
native/captured coordinates, real-piece order, source lexical values and producer attribution.
Raw confidence, interpretation disposition, field state, execution outcome, independent judgment
and publication standing remain separate. Missing output support is not inspected absence.

Extend one semantic release and its compiled storage/report/native/read realizations. A useful
contribution requires no complete-record parent. Retained reports may yield new versioned derived
products only when consumed context and source correspondence suffice; never invent hidden
candidates or change old bytes. Shared invocations and batches do not require per-contribution
transactions. Reuse validated source closure and selected-column reads at the owning scope.

Assess declared operation questions in both directions: source-first for omissions and output-first
for support/duplication/association. Freeze exact regions, rubric and permissible alternatives;
keep their denominators separate. Extend the existing protected source-only frames, immutable
A/B/C passes and evaluator store with a versioned operation protocol. Existing reference fields
may be projected only when they answer the exact new question. Whole-reading Booleans are not
local truth. Paired structural changes require the same cases or explicit correspondence.

This supersedes ADR-0053's universal five-family milestone gate for the progressive milestone.
Its selected author profile survives: fresh gpt-6.1-sol/high A and B source-only sessions and C
adjudication with recorded reasons/provenance; numerical scoring is deterministic. The operator
trusts session independence; no additional isolation machinery is required. CPU extraction has
no general LLM fallback. Preserve original authoring bytes, frozen partitions, guidelines,
reference applicability, native custody and all old grades.

The old 90% capture, 97% accepted precision, one-sided 95% bound of 95%, and 70% accepted recall
remain historical stronger whole-record targets with their original finite-population meanings.
They are not universal local-contribution gates. New capability claims name operation/version,
population, input policy, rubric, actual findings and limits. No universal 0.99 threshold or
calibration model is required; retention alone grants no semantic authority.

Qualified local public admission, contextual embeddings before records, scoped links distinct
from identity, local mathematical queries and complete review exports are accepted targets under
RC04–08. Their implementations remain PCE-04 onward; existing whole-record admission, exclusions,
sealed-label authorization and scientific-support boundaries survive until those owners extend
contracts. PCE-00–03 neither bypass admission nor deploy those later capabilities.

## Consequences

Useful partial structure survives later failure and can be independently assessed. Typed roots,
compiled projections and protected operation protocols require coordinated migrations and
consumer changes. Source/report sharing and operation-owned reads avoid repeated reconstruction;
no speed/capacity benefit is measured by accepting the design.

[The PCE coordinator](../plans/progressive-corpus-enrichment_2026-11-04.md) owns current state,
review O01–O10 and surviving M1 obligations. All implementation/native/semantic qualification
remains open until recorded there. Original plans, evidence, migrations and retained results stay.
The predecessor record remains accessible while historical plans/reviews cite its original targets.
