## Context

M1 needs related notes/declarations and retained recognition alternatives without replacing the
canonical source. Native100 private records deliberately support only same-selected-view pins.
Its recognized_text label resolves canonical node.text; it cannot authenticate a recognition-input
occurrence. Context1 refuses every synthetic crossing and repeatedly prepares full frames when
many bounded contexts share a source. The scoped independent
[source-evidence review](../design_review/reviews/design_review_m1-source-evidence_2026-11-03.md)
consumes audit M1-20261103-r2 and accepts the extension at Proposed target strength.

## Options

Keep the same-view subset as the final design: technically honest but insufficient for the
selected M1 outcome. Append recognition strings to canonical text or trust application-supplied
coordinate proofs: reject, because source identity/precision or native enforcement is lost.
Introduce a general locator framework, evidence service or separate store: reject, because the
concrete selected-view and retained-occurrence custody owners already exist. Compose narrowly
typed source bindings and explicit reading policy with those owners: selected.

## Decision

The effective semantic release owns versioned source-binding/address variants, relationship and
reading policies. Keep the primary source occurrence pin. A related-view anchor retains its own
complete pin and declared relation; initially ordinary related selected views use the same native
product. Authenticate every consumed view against run-selected membership and persisted placement.
Occurrence-defining anchors remain primary unless the released occurrence recipe says otherwise.

A captured-recognition address identifies selected source/occurrence, exact retained recognition
ProductReference/occurrence, admitted typed lineage and captured-text subrange. Exactness of that
string slice is separate from original provider PDF address/region precision. Preserve provider
start/end and unknown/coarse/block precision unchanged. A new distinct address cannot infer its
source from the old recognized_text label. Compose protected selected-record endpoints with
retained recognition bodies at native ingress; unsupported lineage or unchecked text refuses.
Python traces and supplied coordinate text alone are not native admission authority.

A new context version permits policy-declared ordered readings of real pieces separated only by
synthetic whitespace. Evidence carries original pieces, never a synthetic locator or joined quote.
Gap positions and model span remain diagnostics; normalized display is a separate transformation.
Synthetic labels/punctuation, synthetic-only spans, lossy mappings and unsupported preprocessing
still refuse. Old proposal frames2/3 and context1 retain their meanings.

The context owner prepares each immutable source's pins, partition, item/cell and interval index
once within a bounded invocation/run-owned lifetime, then composes selected slices. No global
cache, durable preparation store or additional reuse authority is introduced. Full dependency
identity includes considered/rejected alternatives, relation policy and retrieval outcomes.
Source substitution creates a new context/computation, even when strings happen to match.

OCR word/line evidence admission is explicitly unsupported until a bounded protected native route
authenticates decoded addresses against sealed payload custody. Existing authenticated IPC and
OCR validators remain useful reader capabilities; actual retained inventory is unknown. This
exclusion is not a claim that OCR capability or data is absent.

## Consequences

D1/D2 own source/evidence meanings; D3 owns native authentication; the context owner supplies scoped
prepared composition; producers retain every actual source/precision; publication and consumers
adopt these same bindings. The cost is coordinated released shape, pure binder, native ingress and
reader evolution. It avoids consumer reconstruction, repeated full-frame parsing and a parallel
store. The scoped design is qualitative fit, not measured CPU/RSS, accuracy or release qualification.

M1-03/05 own implementation and direct native forgery/stale/lineage/precision controls; M1-11 owns
public adoption. Preserve native100 and frozen predecessor archives, exact implementation matching,
private accepted-standing refusal and graph product fences. Add a forward migration when the new
native boundary is coherent; no live database/default is migrated by this decision. The
[M1 coordinator](../plans/first-production-milestone_2026-11-03.md) owns current disposition.
