## Context

The selected structural comparison and dossier consumers need an actual successor to
run-qualified structural assertions. The existing policy admits one exact source-resolved
whole statement only after independent A/B answers and C adjudication, matching source frame,
question, rubric and all selected passages. Computational support cannot supply this judgment.
Current generic reference comparisons and rich scientific admission do not implement that policy.
The DDO coordinator owns implementation and qualification; accepting this decision closes neither.

## Options

1. Treat a private report, generic C comparison, or scientific-rich accepted flag as structural
support. Rejected: these have different questions and custody, and do not retain the actual
A/B/C parent population or establish this structural policy.
2. Retain a structural assertion table, latest-pass lookup and separate publication protocol.
Rejected: this preserves the superseded selection authority and duplicates effect, trust,
revocation, receipt and export custody already owned by DDO.
3. Issue an ordinary structural conclusion through the existing protected evaluator command
and explicit authority-leaf boundary of ADR-0110. Selected. Immutable authored passes
retain full attribution and parents, while ordinary readers receive only the permitted statement.

The third option adds a typed structural policy application, rather than another lifecycle.
Native product/member/context identity authenticates the complete report, so the issuer does
not duplicate the typed report owner's derived `structural_id` algorithm. That derived value
remains useful for dossier binding at its current consumer.

## Decision

A dedicated evaluator command consumes the exact native comparison whole and three protected
original authored reference-pass products. A/B have no adjudication parents; C identifies the
actual A/B native products and exact body identities. All passes share the exact immutable
source inputs, question, report address, direction and structural rubric. Output-first exposure
and source-first declarations remain distinct. A unique supported C whole-statement case must
cover every selected source passage and equal the independently lowered structural statement.
The common native completion validates original authored admissions, the actual submitted
principal and author assertion, typed actor identities, complete input support and exact output.

Authored actor identities establish independently attributed judgments at their recorded strength.
They do not attest that a provider executed or independently verify provider session isolation.
Original admission records retain the submitted database principal and author assertions. No
CPU receipt, provider run, scientific truth or member truth is fabricated from those assertions.

The ordinary conclusion names the actual native report address, structural policy and permitted
source-resolved statement. It excludes protected answers, frames, actor identities and parent
addresses. `statement_meaning_json` is versioned canonical JSON of the existing tagged
`semantic_value` representation, preserving integer, float and Decimal meaning without a JSONB
numeric approximation. Native lowering copies the exact tagged report subtrees and constructs
the same source-resolved statement. The admission product's native identity supplies assertion
identity; no legacy claim hash or scientific proposition identity is introduced.

Ordinary support stops at the explicit native authority leaf from ADR-0110. Full protected
support, validity, trust locks, reverse impact and revocation remain with common native custody.
Copied or authored same-kind conclusions have no issuer authority. Exact immutable A/B/C pins
replace implicit newest-row lookup: a new pass changes an explicit selection and never silently
reinterprets a retained admission. Currentness can be inspected explicitly.

## Consequences

The selected supported-comparison gap can inspect one genuine admitted conclusion and exact
dossier binding under the same read cut. Missing admission, unselected output or unsupported
policy remains unavailable; it never establishes absence or a missing scientific fact.
Detached replay authenticates the permitted conclusion and explicitly bounded provenance,
while retaining unknown protected details. Initial implementation is bounded to the existing
qualified-comparison policy. Other structural policies require their own faithful application.
Native hooks, actual evaluator authoring, consumer migration, old-reader retirement and final
qualification remain with the DDO coordinator until implemented and verified.
