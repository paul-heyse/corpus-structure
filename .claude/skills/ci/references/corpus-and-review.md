## Prepare and inspect the exact native demand

```sh
uv run ci status --demand DEMAND_ID --project PROJECT --json
uv run ci tasks --demand DEMAND_ID --project PROJECT --json
uv run ci run --request REQUEST.json --source-root ROOT --json
uv run ci run resume DEMAND_ID --project PROJECT --source-root ROOT --json
```

Select the explicit demand and project when interpreting progress. Without a demand, `ci status`
shows settings; it does not choose a latest run. Follow bounded frontier continuations rather than
interpreting an incomplete page as an absent population. Native requests, generations, attempts,
leases and retained publication receipts own execution and recovery.

Use `ci ingest` for declared source preparation, or the ordinary `ci run` source choices for the
intended workflow. Current source selection freezes original documents, exact admitted release and
runtime, declared targets and explicit alternatives. Use group help for available source/scope/profile
options; historical integer runs and task-layer selections do not supply current demand identity.

Use `source`, `records`, `contributions`, `structure`, `query` and `explain` to inspect selected
products and evidence. Reads require their exact demand/project/cut and bounded continuation pins.
Private proposal, resolved reading, independently admitted conclusion and scientific truth are
different standings. Protected reference authoring/evaluation and fitting use the purpose-specific
`golden` and `eval` groups with explicit request files. `eval structural` requires exactly the native
structural adjudication target; independent authored attribution does not verify external actor execution.

## Export and verify current selected closure

```sh
uv run ci review export --demand DEMAND_ID --project PROJECT --out DESTINATION --json
uv run ci review verify ARTIFACT --manifest-digest TRUSTED_SHA256 --json
uv run ci structure export REQUEST.json DESTINATION --json
uv run ci structure verify ARTIFACT TRUSTED_SHA256 --json
```

Selected export captures actual native source/support/contracts/runtime on the acquiring session.
Keep the trusted manifest digest separately from the detached artifact and provide it for verification.
The [selected export owner](../../../../python/corpus-structure/src/corpus_structure/serve/demand_export.py)
and [structural selection model](../../../../python/corpus-structure/src/corpus_structure/serve/selected_structural_review.py)
own these current formats. Ordinary protected dependencies remain undisclosed through authenticated
bounded native authority; a detached read cannot establish current permission or verify hidden judgments.

Inspect an operation's managed result by ID when its command publishes one. An export destination
is a deliberate detached artifact, not an old review-bundle managed result or retry token. Use the
[managed results reference](testing-and-results.md) for custody, retrieval and retained failures, and
actual command help for supported recovery. Obsolete retained-review/golden/eval adapters and the
old internal review-bundle decoder are retired.
